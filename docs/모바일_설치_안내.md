# X-Manager 모바일 설치 안내 (직원용)

X-Manager는 별도 앱 설치 없이 **휴대폰 홈 화면에 "웹앱"으로 설치**해서 앱처럼 쓸 수 있습니다.
(설치형 PWA — 아이콘 탭하면 전체화면으로 실행됩니다.)

## 접속 주소
**반드시 HTTPS 도메인으로 접속하세요.** (IP·http 접속은 보안상 설치가 막힙니다)
- 예: `https://xmanager.xbeamtech.co.kr`
- 모바일 접속 시 자동으로 모바일 홈 화면으로 열립니다.

---

## 아이폰 (iPhone)
1. **반드시 Safari** 로 위 주소를 엽니다. (Chrome·카카오톡·구글앱 인앱브라우저는 설치 불가)
2. 하단 **공유 버튼(⬆️)** 탭
3. **"홈 화면에 추가"** 선택 → 추가
4. 홈 화면 아이콘으로 실행

## 안드로이드 (Android)
1. **Chrome** 또는 **삼성 인터넷** 으로 위 주소를 엽니다. (카카오톡·구글앱 인앱브라우저는 불가 — 기본 브라우저로 열기)
2. 우측 **⋮ 메뉴** → **"앱 설치"** 또는 **"홈 화면에 추가"**
3. 홈 화면 아이콘으로 실행

### ⚠️ "보안 관련 문제로 설치할 수 없음" 경고가 뜰 때
이건 사이트 문제가 아니라, 안드로이드가 **스토어 밖 앱 설치를 기본 차단**하기 때문입니다. 두 가지 방법:
- **그냥 진행**해도 안전합니다(사내 사이트, 정식 보안 인증서). 바로가기로 설치됩니다.
- **경고 없이 정식 앱으로** 설치하려면, 브라우저에 "알 수 없는 앱 설치" 권한 허용:
  - **설정 → 애플리케이션 → (Chrome 또는 삼성 인터넷) → 알 수 없는 앱 설치 → 허용**
  - 또는 **설정 → 보안 및 개인정보 보호 → 알 수 없는 앱 설치 → 해당 브라우저 → 허용**
  - 허용 후 다시 설치하면 경고 없이 독립 앱으로 설치됩니다.

---

## 참고
- 설치하지 않고 브라우저로 그냥 써도 동일하게 동작합니다(설치는 "앱 느낌 + 빠른 접근"용).
- 모바일에서는 **공지 / 전자결재** 등 핵심 업무가 모바일 화면에 맞게 표시됩니다.
  (부품·BOM·재고 등 복잡한 관리 화면은 PC 사용 권장)
- 하단 탭바(홈/공지/결재)로 자주 쓰는 기능에 바로 이동할 수 있습니다.
