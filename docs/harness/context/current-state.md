## 3. v0.24.0 신규 DB 모델

```
신규 테이블:
  sales_document          — 영업 문서 (Q/PI/CI 통합)
  sales_document_item     — 영업 문서 품목
  product_description_code — 오더코드 세그먼트→Description 매핑
  work_order_process_log  — 공정별 시작/완료/소요시간 로그

확장된 테이블:
  business_partner  +5 필드 (short_code, swift_code, bank_address, hs_code, default_margin_rate)
  work_order        +5 필드 (order_subtype, packaging_boxes/dimensions/gross/net_weight)
  sales_document    +6 필드 (payment_status, payment_condition, paid_amount, paid_date, payment_remarks, management_no)
```
