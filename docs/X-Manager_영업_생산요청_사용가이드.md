# X-Manager 영업 대응 → 생산 요청 사용 가이드

**대상**: 영업팀 실무자
**목적**: 영업 대응 → 견적서 → PI → 생산 요청까지 전체 흐름을 X-Manager로 처리하는 방법
**작성일**: 2026-04-09

---

## 전체 프로세스 한눈에 보기

```
1. 영업 대응 기록   →  2. 견적서 작성   →  3. PI 전환   →  4. 생산 요청 생성
   (고객 문의)         (가격/조건 협의)     (고객 PO 수령)     (생산팀 전달)
```

각 단계는 X-Manager 안에서 **버튼 클릭으로 자동 연결**됩니다. 수기로 데이터를 다시 입력할 필요가 없습니다.

---

## 0. 로그인

1. 브라우저에서 `https://xmanager.xbeamtech.co.kr` 접속
2. 본인 아이디/비밀번호로 로그인
3. 로그인 사용자 이름은 **문서 작성자에 자동 입력**됩니다

---

## 1단계: 영업 대응 기록

**언제 사용**: 고객으로부터 문의/메일/전화가 왔을 때

### 위치
좌측 메뉴 → **영업** → **영업 대응 현황** 탭

### 신규 등록
1. 우측 상단 **[+ 신규 등록]** 버튼 클릭
2. 필수 입력 항목:
   - **거래처**: 기존 거래처 검색 또는 직접 입력 (미등록 고객도 가능)
   - **프로젝트명**: `HXB13 4CH 방산 납품` 같은 식별자
   - **문의 유형**: `일반 문의` / `기술 문의` / `견적 문의` / `샘플 요청` / `클레임`
     - 기술 문의는 기술팀에서 별도 확인
   - **담당자**: 로그인 사용자로 자동 채워짐 (수정 가능)
3. 선택 입력:
   - **다음 필요 단계**, **지연 사유**, **예상 금액/통화**
4. **저장**

### 후속 업데이트 (중요)
목록에서 해당 건 클릭 → 상세 모달 오픈

상세 모달에서 **바로 편집 가능한 항목**:
- **상태** (진행중 / 대기 / 완료 / 보류)
- **문의 유형**
- **다음 필요 단계** — 텍스트 클릭 또는 ✎ 수정 버튼
- **지연 사유** — 동일한 방법
- **코멘트 추가** — 진행 상황을 시간 순서대로 기록

### 필터/검색
- 상단 필터: 상태, 담당자, 문의 유형(탭), 키워드 검색
- **기술팀은 "기술 문의" 탭만 클릭**하면 본인 건만 필터됨

---

## 2단계: 견적서 작성

**언제 사용**: 고객에게 가격을 제시할 때

### 진입 방법 2가지

#### A. 영업 대응에서 바로 넘어가기 (추천)
1. 영업 대응 상세 모달 열기
2. 하단 **[📝 견적서 작성]** 버튼 클릭
3. 확인 대화상자 → 해당 영업활동이 자동으로 **"완료" 상태**로 전환
4. **견적서 탭**으로 자동 이동 + 새 견적서 모달 자동 오픈
5. **고객사가 미리 선택**된 상태로 시작
6. **Payment Terms / Bank Details는 자동 로드**됨

#### B. 견적서 탭에서 직접 생성
1. 견적서 탭 → **[+ 신규 등록]** 버튼
2. 고객사 검색 선택

### 견적서 입력 흐름

#### ① 기본 정보
- **고객사**: 검색 선택 (A 방식에서는 자동)
- **문서 날짜**: 오늘로 자동 지정
- **작성자**: 로그인 사용자 자동
- **이메일**: 필요 시 입력

#### ② 거래 조건 (Terms & Bank Details)
- **기본은 편집 잠금** 상태 (🔒)
- 고객사 선택 시 **자동 로드**됨 (거래처에 저장된 기본값)
- **Delivery Terms만 항상 수정 가능** (파란 테두리)
- 다른 항목을 바꾸려면 우측 **"편집 잠금"** 버튼으로 해제

#### ③ 품목 추가
각 품목마다:
1. **오더코드 입력** (예: `HXB13-PSD-B-O4-S1-D55`)
2. 두 가지 방법 중 선택:

   **방법 1: [검색] 버튼 클릭** — 기존 부품에서 선택
   - 완제품만 표시됨 (완제품/유닛/키트)
   - 검색 결과 없으면 **[+ 새 완제품으로 등록]** 버튼으로 바로 등록 가능
   - 선택 시 description, 단가, 이전 견적 가격 자동 조회

   **방법 2: 오더코드 직접 입력 후 [자동] 버튼 클릭**
   - Description이 자동 조합됨 (PSD + B + O4 + S1 + D55 → 각 세그먼트 설명 연결)
   - 등록되지 않은 D직경(`D85` 등)은 **자동 파싱**되어 "for out diameter 8.5mm Outdoor cable"로 표시
   - 매칭 안 된 코드가 있으면 알림 (직접 입력하거나 코드 등록 필요)

3. **수량** 입력 (정수)
4. **단가** 입력 (소수점 2자리 가능)
5. **이전 견적 가격**이 자동 표시됨
   - 같은 고객사가 과거에 받은 가격
   - 현재 단가가 더 높으면 ⚠ 빨간 경고

#### ④ 마진율 일괄 적용
1. 품목 헤더 우측의 **마진율 입력란**에 퍼센티지 입력 (예: `30`)
2. **[적용]** 버튼 클릭
3. 모든 품목의 **현재 단가를 기준가로 저장**한 뒤 마진 적용
4. 단가 아래에 "기준가: XXX" 표시
5. 이후 개별 단가를 수동으로 조정 가능
6. 필요 시 마진율을 바꿔서 다시 [적용]하면 **기준가 기반으로 재계산** (누적 X)

#### ⑤ 저장
- **저장 → DRAFT 상태**
- 확인 후 목록에서 **[발송]** 버튼 클릭하면 **SENT 상태**로 변경

### 엑셀 다운로드
목록에서 해당 견적서의 **[엑셀]** 버튼 클릭 → 완성된 견적서 파일 다운로드 (고객 발송용)

---

## 3단계: PI 전환 (고객 PO 수령 시)

**언제 사용**: 고객이 PO를 보내 "주문 확정"했을 때

### 진입
견적서 목록 → 해당 견적서 우측의 **[PI전환]** 버튼

### PI 전환 모달
1. **PO 번호** 입력 (선택, 없으면 "메일주문" 같은 참조 메모)
2. **PO 날짜** 입력 (선택)
3. **PO 첨부파일** 업로드 (선택, 다중 파일 가능)
4. **[PI 전환]** 클릭

### 전환 후
- 원본 견적서는 **CONFIRMED** 상태로 변경
- 새 PI 문서가 **DRAFT** 상태로 생성
- 품목/금액/Terms 모두 복사됨
- 견적서 편집 화면에 **노란색 경고**: "이미 PI로 전환됨"

### PI 관리
**영업** → **PI / CI** 탭에서 확인

목록 특징:
- **미입금이 최상단**, 부분입금 → 완납 순으로 자동 정렬
- **미입금은 빨간 배경**, 부분입금은 노란 배경
- 상단 **입금 필터** 탭으로 빠르게 조회

입금 상태 변경:
- 입금 뱃지 클릭 → 상태/금액/확인일/메모 입력

---

## 4단계: 생산 요청 생성

**언제 사용**: PI 발행 후, 생산팀에 작업을 넘길 때

### 진입 방법 2가지

#### A. PI 편집 모달에서 (추천)
1. PI / CI 탭에서 해당 PI 클릭 → 편집 모달
2. 상단의 **📦 생산 진행 현황** 박스 확인
   - 품목별 **[PI 수량 / 요청됨 / 잔여]** 테이블
3. **[+ 생산요청 생성]** 버튼 클릭
4. 확인 대화상자 → 자동 생성
5. **생산요청 페이지로 자동 이동** + 해당 요청서 모달 자동 오픈

#### B. PI 목록에서 빠르게
1. PI / CI 탭 → 해당 PI 줄의 **[생산요청]** 버튼
2. 잔여 수량 체크 → 확인 → 자동 생성

### 자동 채워지는 항목
- **생산번호** (자동 채번)
- **거래처** (PI의 고객사)
- **국가**
- **PI번호**
- **PO번호**
- **입금현황** (PI의 입금상태 복사)
- **품목 + 수량** (잔여 수량만)
- **작성자** (로그인 사용자)

### 영업팀이 추가 입력할 항목
1. **납기일** — 생산팀과 협의 후 입력
2. **생산기간** (예: "5주")
3. **고객 요구사항** (품목별)
4. **SHIPPING MARK / CONSIGNEE** — 수출 건
5. **비고** — 특이사항
6. **첨부파일**
   - 이미지는 **Ctrl+V 붙여넣기**로 바로 첨부 가능
   - PDF/엑셀 등 파일 업로드

### 저장 및 상태
- **저장** → `REQUESTED` 상태
- 생산팀이 확인 후 `APPROVED`로 변경

---

## 5단계: 분할 생산요청 (부분 생산)

**언제 사용**: PI 100EA 중 60EA만 먼저 생산하고 싶을 때

### 흐름
1. 첫 번째 PR 생성 (자동 100EA로 채워짐)
2. PR 편집 모달에서 **수량을 60EA로 수정** → 저장
3. 같은 PI 편집 모달 재진입 → **잔여 수량 40EA 표시**
4. **[+ 생산요청 추가]** 버튼 → 두 번째 PR 생성 (40EA 자동)

### 주의사항
- 잔여 수량이 **0이면 "전 품목 생산요청 완료"** 메시지 표시, 추가 생성 불가
- 분할 PR은 비고에 `[PI 자동생성 (분할 #2)]` 표시됨
- PI 편집 모달 하단 **"연결 문서"** 영역에 연결된 모든 PR이 버튼으로 표시됨

---

## 6단계: 문서 간 이동 (양방향 네비게이션)

모든 영업 문서 편집 모달 상단에 **"연결 문서"** 네비게이션 영역이 있습니다.

### 견적서 편집 중
- **← 없음** (견적서가 시작점이므로)
- **→ PI PI-XXX** (전환된 PI가 있으면)

### PI 편집 중
- **← QUOTATION Q-XXX** (원본 견적서)
- **→ CI CI-XXX** (전환된 CI가 있으면)
- **→ 생산요청 PR-XXX** (연결된 생산요청, 여러 개 가능)

### 클릭 시
- **같은 탭 안 문서**: 현재 모달 닫고 해당 문서 모달 오픈
- **다른 탭 문서**: 자동으로 탭 전환 + 모달 오픈
- **생산요청**: 생산요청 페이지로 이동 + 모달 오픈

## 자주 묻는 질문

### Q1. 부품 코드가 없는 신규 제품은 어떻게?
견적서 품목에서 **[검색]** → **[+ 새 완제품으로 등록]** → 품번/품명/단가만 입력하면 즉시 등록됩니다. 추후 기술팀이 정식 분류/BOM을 보완합니다.

### Q2. 견적서를 수정하면 PI도 자동 수정되나요?
**아니요.** PI는 법적 효력이 있는 문서라 자동 동기화하지 않습니다. 견적서를 수정하면 모달 상단에 경고가 뜨므로, 필요 시 PI도 별도로 수정하세요.

### Q3. 거래처 담당자 이름을 잘못 입력했어요
거래처 편집 모달에서 **담당자명/직책/연락처** 수정 가능. 이 정보는 모든 새 견적서/PI에 자동 로드됩니다.

### Q4. 단가가 이전 견적보다 낮게 나왔는데 확인 가능한가요?
견적서 품목 아래에 **이전 견적 가격**이 자동 표시됩니다. 현재 단가가 이전보다 낮으면 파란색, 높으면 ⚠ 빨간색으로 경고합니다.

### Q5. PI 한 건에 여러 생산요청을 만들 수 있나요?
네. PI 편집 모달의 **📦 생산 진행 현황** 테이블에서 **잔여 수량만큼** 계속 추가 가능합니다. 잔여 0이 되면 더 이상 만들 수 없습니다.

### Q6. 이미지를 생산요청서에 첨부하려면?
스크린샷 캡처 후 생산요청 폼에서 **Ctrl+V 붙여넣기**. 이미지 파일이 자동으로 첨부됩니다.

### Q7. 작성한 문서를 고객에게 보내려면?
각 목록의 **[엑셀]** 버튼으로 정식 양식 다운로드. 메일/프린트로 전달하세요.

## 문제 발생 시

### 로그인이 안 되거나 페이지가 열리지 않을 때
- 브라우저 강력 새로고침: **Ctrl + Shift + R**
- 그래도 안 되면 관리자에게 연락

### 데이터가 안 보일 때
- 상단 필터에 설정된 값이 있는지 확인 (상태, 고객사 등)
- "전체"로 초기화 후 다시 검색

### 잘못 저장했을 때
- 대부분의 문서는 **편집 모달에서 수정 가능**
- 완전 삭제가 필요한 경우 관리자에게 요청

## 전환 기간 권장사항

**1~2주는 노션 + X-Manager 병행 운영**을 권장합니다.

1. 신규 발생 건부터 X-Manager에 입력
2. 노션은 진행 중인 기존 건만 유지
3. 실무자끼리 사용 중 발견한 불편사항 수집
4. 1주일마다 개선사항 반영
5. 안정되면 노션 단독 모드 종료
