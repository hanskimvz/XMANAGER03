### 우선순위 1: 즉시 필요 (Critical) 🔴

#### 1.1 에러 핸들링 개선
**현재 문제**:
- API 에러가 사용자 친화적이지 않음
- 네트워크 오류 시 명확한 메시지 없음

**개선 방안**:
```typescript
// frontend/src/utils/errorHandler.ts (신규)
export function handleApiError(error: any): string {
  if (error.response) {
    // 서버 응답 에러
    const status = error.response.status
    const detail = error.response.data?.detail

    switch (status) {
      case 400: return `입력 오류: ${detail}`
      case 404: return '데이터를 찾을 수 없습니다'
      case 500: return '서버 오류가 발생했습니다'
      default: return detail || '알 수 없는 오류'
    }
  } else if (error.request) {
    // 네트워크 에러
    return '서버에 연결할 수 없습니다'
  } else {
    return '요청 처리 중 오류가 발생했습니다'
  }
}
```
