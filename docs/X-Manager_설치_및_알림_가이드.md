# X-Manager 앱 설치 · 알림 받기 가이드

X-Manager는 **홈 화면에 앱으로 설치**해서 쓰면, 앱을 닫아도 **결재·공지 알림이 휴대폰으로** 옵니다.
아래 순서대로만 하면 됩니다.

> 접속 주소: **https://xmanager.xbeamtech.co.kr**

---

## ⚠️ 가장 중요한 규칙 (꼭 지켜주세요)

**알림은 "홈 화면에 설치한 앱" 안에서 켜야 합니다.**
브라우저(크롬/사파리) 탭에서 알림을 켜면 안 됩니다.

- ❌ 크롬/사파리 탭에서 알림 켜기 → 안드로이드는 알림 누르면 브라우저로 열리고, **아이폰은 알림이 아예 안 옵니다.**
- ✅ 홈 화면 앱으로 설치 → **앱을 열고** → 앱 안에서 알림 켜기

즉 순서는 항상 **① 홈 화면에 설치 → ② 설치된 앱 아이콘으로 열기 → ③ 앱 안에서 알림 켜기** 입니다.

---

## 📱 안드로이드 (갤럭시 등) — 크롬 기준

### 1단계. 앱 설치
1. **크롬(Chrome)** 으로 https://xmanager.xbeamtech.co.kr 접속 후 로그인
2. 우측 상단 **⋮ (점 3개) 메뉴** 탭
3. **"앱 설치"** 또는 **"홈 화면에 추가"** 선택 → 설치
4. 홈 화면에 생긴 **X-Manager 아이콘(파란 배경 X)** 확인

> 삼성 인터넷 브라우저를 쓰면 메뉴 → "현재 페이지 추가 → 홈 화면"으로도 설치되지만,
> **알림 기능은 크롬으로 설치하는 것을 권장**합니다.

### 2단계. 알림 켜기 (앱 안에서!)
1. 방금 설치한 **홈 화면의 X-Manager 아이콘으로 앱을 엽니다.** (크롬 탭 아님)
2. 오른쪽 위 **🔔 종 아이콘** 탭
3. **"휴대폰·PC 알림 켜기"** 탭 → 팝업에서 **허용**
4. "✅ 알림이 켜졌습니다" 가 뜨면 완료

### 3단계. 확인
- 공지가 등록되거나 내 결재 차례가 되면, **앱을 닫아도** 휴대폰 상단에 알림이 뜹니다.
- 알림을 누르면 **X-Manager 앱**이 열립니다.
  (만약 크롬으로 열린다면, 알림을 크롬 탭에서 켠 것입니다 → 아래 "문제 해결" 참고)

## 🍎 아이폰 (iPhone) — 사파리 기준

> **주의: 아이폰은 조건이 까다롭습니다.**
> - **iOS 16.4 이상** 이어야 합니다. (설정 → 일반 → 정보 → 소프트웨어 버전 확인, 낮으면 업데이트)
> - **반드시 홈 화면에 추가한 뒤, 그 앱 아이콘으로 열어서** 알림을 켜야 합니다.
> - 사파리 탭 상태에서는 알림을 켤 수 없고, 켜지지도 않습니다.

### 1단계. 앱 설치
1. **사파리(Safari)** 로 https://xmanager.xbeamtech.co.kr 접속 후 로그인
   (크롬 아님 — 아이폰은 반드시 사파리로 설치해야 알림이 됩니다)
2. 하단 가운데 **공유 버튼 (□ 위로 화살표)** 탭
3. 목록에서 **"홈 화면에 추가"** 탭 → **추가**
4. 홈 화면에 생긴 **X-Manager 아이콘(파란 배경 X)** 확인

### 2단계. 알림 켜기 (앱 안에서!)
1. **홈 화면의 X-Manager 아이콘으로 앱을 엽니다.** (사파리 아님)
2. 오른쪽 위 **🔔 종 아이콘** 탭
3. **"휴대폰·PC 알림 켜기"** 탭 → 팝업에서 **허용**
4. "✅ 알림이 켜졌습니다" 가 뜨면 완료

### 3단계. 확인
- 잠금 화면/알림 센터에 X-Manager 알림이 뜨는지, 공지/결재로 테스트해 보세요.

## 🔔 알림이 안 올 때 — 체크리스트

순서대로 확인하세요.

1. **홈 화면 앱으로 열었나요?** (브라우저 탭 아님)
   → 홈 화면 아이콘으로 앱을 연 상태에서 종 아이콘 → 알림 켜기.
2. **알림 켤 때 "허용" 을 눌렀나요?**
   → 종 아이콘 눌렀을 때 "브라우저 알림이 차단됨" 이라고 뜨면, 아래 "차단 해제" 참고.
3. **(아이폰) iOS 16.4 이상인가요?**
   → 낮으면 소프트웨어 업데이트 후 다시 설치.
4. **휴대폰 자체 알림 설정이 꺼져있지 않나요?**
   → 설정 → 앱 → X-Manager → 알림 허용 확인.
5. **절전/방해금지 모드**가 알림을 막고 있지 않은지 확인.

### 알림 권한이 "차단됨" 으로 뜰 때
한 번 "차단"을 누르면 버튼만으로는 다시 못 켭니다. 아래처럼 해제하세요.
- **안드로이드/크롬**: 앱에서 주소창 옆 정보 → 사이트 설정 → 알림 → **허용**
- **아이폰**: 설정 → 알림 → X-Manager → **알림 허용** 켜기
- 그 뒤 앱에서 종 아이콘 → "알림 다시 켜기"

## 🔁 안드로이드에서 알림을 눌렀더니 "크롬"으로 열려요

원인: **알림을 크롬 탭에서 켰기 때문**입니다. (크롬이 알림 주인이 됨)
해결:
1. 홈 화면의 X-Manager 앱을 **삭제**
2. 크롬으로 사이트 재접속 → **다시 앱 설치**
3. 홈 화면 앱을 **열고** → 종 아이콘 → **알림 켜기**
→ 이후 알림을 누르면 X-Manager 앱으로 열립니다.

---

## 🖼️ 아이콘이 예전 것으로 보여요 / 안 바뀌어요

앱 아이콘은 설치 시점에 저장돼서 **새로고침으론 안 바뀝니다.** 재설치가 필요합니다.
1. 홈 화면의 기존 X-Manager 앱 **삭제**
2. (안드로이드) 크롬 → 주소창 🔒 → 사이트 설정 → **데이터 삭제** 후 재접속
3. **다시 설치** → 새 아이콘으로 설치됩니다

> PC 브라우저 탭 아이콘(favicon)이 옛 것이면 **Ctrl + Shift + R** (강력 새로고침).

---

## 💻 PC(데스크톱)에서도 알림 받기

1. **크롬/엣지**로 https://xmanager.xbeamtech.co.kr 접속
2. 주소창 오른쪽 **설치 아이콘(⊕/모니터 모양)** 클릭 → 앱 설치 (선택)
3. 종 아이콘 → **"알림 켜기"** → 허용
→ 브라우저를 꺼도(백그라운드 실행 중이면) 알림이 뜹니다.

## ❓ 자주 묻는 질문

**Q. 꼭 설치해야 하나요? 그냥 브라우저로 쓰면 안 되나요?**
A. 조회·작성은 브라우저로도 됩니다. 다만 **앱을 닫아도 오는 푸시 알림**은
   홈 화면에 설치하고 앱 안에서 알림을 켰을 때만 옵니다. (특히 아이폰은 설치 필수)

**Q. 알림 소리는 나나요?**
A. 휴대폰의 X-Manager 알림 설정(소리/진동)을 따릅니다. 설정 → 앱 → X-Manager → 알림에서 조정하세요.

**Q. 로그아웃하면 알림이 끊기나요?**
A. 다시 로그인하면 자동으로 이어집니다. 기기를 바꾸면 새 기기에서 다시 설치·알림 켜기를 해주세요.
