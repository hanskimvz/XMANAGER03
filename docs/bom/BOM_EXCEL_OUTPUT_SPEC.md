# BOM 엑셀 출력 지침서 (Claude Skills용)

> **목적**: 제품 문서를 분석하여 BOM을 생성한 후, X-MANAGER에 업로드 가능한 엑셀 파일로 출력하기 위한 규격
> **최종 수정**: 2026-03-04

---

## 1. 엑셀 파일 기본 규격

| 항목 | 값 |
|------|---|
| 파일 형식 | .xlsx |
| 시트 | 1개 (첫 번째 시트만 읽음) |
| 1행 | 헤더 (선택사항, 있으면 자동으로 건너뜀) |
| 2행~ | 데이터 |
| 인코딩 | UTF-8 |

---

## 2. 컬럼 구조 (A~G, 총 7개)

| 컬럼 | 헤더명 | 필수 | 데이터 타입 | 설명 |
|:----:|--------|:----:|-----------|------|
| **A** | 레벨 | **필수** | 문자열 | `L1`, `L2`, `L3`... 또는 `U` |
| **B** | 품번 | **필수** | 문자열 | 전체 품번 + 레벨 접미사 `[X]` |
| **C** | 품명 | 선택 | 문자열 | 부품 이름 |
| **D** | 규격 | 선택 | 문자열 | 사양/스펙 |
| **E** | 수량 | 선택 | 숫자 | 기본값: 1 |
| **F** | 단위 | 선택 | 문자열 | `EA`, `LOT`, `SET` 등. 기본값: EA |
| **G** | 비고 | 선택 | 문자열 | 메모/참고사항 |

---

## 3. 레벨(A열) 규칙

### 3.1 레벨 표기법

| 표기 | 의미 | 설명 |
|------|------|------|
| `L1` | 최상위 부품 (Parent) | 새로운 BOM 트리의 시작 |
| `L2` | L1의 직접 하위 부품 | L1에 포함되는 부품 |
| `L3` | L2의 직접 하위 부품 | L2에 포함되는 부품 |
| `L4` | L3의 직접 하위 부품 | (이하 동일) |
| `L5+` | 더 깊은 하위 | 깊이 제한 없음 |
| `U` | Unit (유닛) | L1과 동일한 최상위, 사용 시 레벨이 자동 변환됨 |

### 3.2 필수 규칙

```
규칙 1: 첫 번째 데이터 행은 반드시 L1 (또는 U)이어야 한다
규칙 2: 레벨 점프 불가 — 1단계씩만 깊어질 수 있다
         L1 → L2  (O)
         L2 → L3  (O)
         L2 → L4  (X) ← 오류 발생
규칙 3: 같은 레벨로 돌아가는 것은 허용
         L3 → L3  (O) ← 같은 부모의 다른 자식
         L3 → L2  (O) ← 상위로 돌아감
규칙 4: L1이 다시 나오면 새로운 BOM 트리 시작
         하나의 엑셀에 여러 BOM 트리를 포함할 수 있음
```

### 3.3 U (Unit) 사용 시 자동 변환

U가 엑셀에 하나라도 존재하면, 모든 레벨이 +1 변환됩니다.

```
엑셀 입력:     → 시스템 내부 처리:
U   → L1
L1  → L2
L2  → L3
L3  → L4
```

> **권장**: 혼동을 피하려면 U와 L1을 혼용하지 말고, 하나만 사용하세요.
> - 일반적인 경우: L1, L2, L3... 사용
> - 유닛(완성품) 개념이 필요한 경우: U, L1, L2... 사용

## 4. 품번(B열) 규칙

### 4.1 품번 형식

```
{품번} [{레벨코드}]

예시:
  HXB15-PSD-B-O4-S1-D55 [U]
  HB05-PLP-FSO-01-A6-HB [S]
  HB05-PLP-BBO-01-A6-NN [R]
```

### 4.2 레벨코드 접미사 (대괄호)

품번 뒤에 대괄호로 해당 부품의 레벨(종류)을 표시합니다.

| 접미사 | 레벨 코드 | 의미 | 설명 |
|:------:|:---------:|------|------|
| `[U]` | F | Unit / Finished Good | 최종 완성품 또는 유닛 |
| `[F]` | F | Finished Good | 완성품 |
| `[K]` | K | Kit | 키트 (조립 세트) |
| `[P]` | P | Package | 패키지 |
| `[S]` | S | Sub-Assembly | 서브조합 (반제품) |
| `[C]` | C | Combination | 조합 부품 |
| `[R]` | R | Raw Component | 원자재/원부품 |
| `[O]` | O | Outsourcing | 외주 가공품 (단위: LOT) |
| `[M]` | M | Manufacturing | 제조 가공품 |

### 4.3 품번 규칙

```
규칙 1: 품번은 공백 없이 정확하게 입력
규칙 2: 대괄호 접미사와 품번 사이에 공백 1개
         HB05-PLP-FSO-01-A6-HB [S]   (O)
         HB05-PLP-FSO-01-A6-HB[S]    (O, 공백 없어도 인식)
         HB05-PLP-FSO-01-A6-HB  [S]  (O, 공백 여러 개도 인식)
규칙 3: 레벨코드 대괄호는 대문자
         [S] (O)    [s] (O, 소문자도 인식됨)
규칙 4: DB에 없는 품번은 자동 생성됨
         - 품명: 엑셀 C열 값 사용, 없으면 품번과 동일
         - 단위: 기본 EA, 외주[O]는 LOT
         - 레벨: 접미사에서 자동 추출
```

---

## 5. 수량(E열) 규칙

```
규칙 1: 숫자만 입력 (정수 또는 소수)
규칙 2: 빈칸이면 기본값 1.0 적용
규칙 3: 0 이하의 값은 오류 발생
규칙 4: 소수점 사용 가능 (예: 0.5, 2.5)
```

---

## 6. 단위(F열) 규칙

```
규칙 1: 시스템에 등록된 단위명 사용 (EA, LOT, SET, PCS 등)
규칙 2: 빈칸이면 단위 미지정 (부품의 기본 단위 사용)
규칙 3: 대소문자 구분 없음 (ea = EA)
```

## 7. BOM 트리 구조 예시

### 7.1 단일 BOM 트리

```
레벨 | 품번                          | 품명              | 규격 | 수량 | 단위 | 비고
L1   | HXB15-PSD-B-O4-S1-D55 [U]    | HXB15 플러그 유닛 |      | 1    | EA   |
L2   |   HXB15-PSD-B-STD [K]        | 쉘 키트           |      | 1    | EA   |
L3   |     HB05-PLP-FSO-01-A6-HB [S]| 프론트쉘          |      | 1    | EA   |
L3   |     HB05-PLP-BBO-01-A6-HB [C]| 백쉘              |      | 1    | EA   |
L4   |       HB05-PLP-BBO-01-A6-NN [R]| 백쉘 소재       |      | 1    | EA   |
L2   |   HXB15-PSD-CNT-01 [S]       | 컨택트            |      | 15   | EA   |
L2   |   HXB15-PSD-GSK-01 [R]       | 가스켓            |      | 2    | EA   |
```

위 구조의 의미:
```
HXB15 플러그 유닛 [U] (L1)
├── 쉘 키트 [K] (L2) x1
│   ├── 프론트쉘 [S] (L3) x1
│   └── 백쉘 [C] (L3) x1
│       └── 백쉘 소재 [R] (L4) x1
├── 컨택트 [S] (L2) x15
└── 가스켓 [R] (L2) x2
```

### 7.2 다중 BOM 트리 (하나의 엑셀에 여러 제품)

```
레벨 | 품번                          | 품명              | 규격 | 수량 | 단위 | 비고
L1   | HXB15-PSD-B-O4-S1-D55 [U]    | HXB15 플러그 유닛 |      | 1    | EA   |
L2   |   HXB15-PSD-B-STD [K]        | 쉘 키트           |      | 1    | EA   |
L3   |     HB05-PLP-FSO-01-A6-HB [S]| 프론트쉘          |      | 1    | EA   |
L1   | HXB15-RCP-A-O4-S1-D55 [U]    | HXB15 리셉 유닛   |      | 1    | EA   |
L2   |   HXB15-RCP-A-STD [K]        | 리셉 쉘 키트      |      | 1    | EA   |
L3   |     HB05-RCP-FSO-01-A6-HB [S]| 리셉 프론트쉘     |      | 1    | EA   |
```

> L1이 다시 나오면 이전 BOM 트리는 종료되고 새로운 트리가 시작됩니다.

## 8. 업로드 모드

| 모드 | 값 | 설명 |
|------|---|------|
| **교체** | `replace` | 기존 L1(상위 부품)의 BOM을 삭제하고 새로 등록 |
| **추가** | `append` | 기존 BOM 유지, 새로운 항목만 추가 |

> 자동화 프로세스에서는 `replace` 모드가 적합합니다. (최신 문서 기반으로 BOM을 완전히 재생성)

---

## 9. 검증 규칙 요약

업로드 시 시스템이 자동으로 검증하는 항목들입니다.

| 검증 항목 | 조건 | 결과 |
|-----------|------|------|
| 첫 행 레벨 | L1 또는 U가 아니면 | 오류 |
| 레벨 점프 | L2 → L4 같은 점프 | 오류 |
| 순환 참조 | A → B → A 같은 구조 | 오류 |
| 자기 참조 | 부품이 자신을 하위로 포함 | 오류 |
| 수량 | 0 이하 | 오류 |
| 미등록 품번 | DB에 없는 품번 | 경고 (자동 생성) |
| 기존 BOM 존재 | replace 모드에서 덮어쓰기 | 경고 |

## 10. Claude Skills 최종 출력 지침

### 10.1 출력 프로세스

```
1. 제품 문서 분석 → 부품 구조 파악
2. 부품 계층 구조 정리 (Parent → Child 관계)
3. 각 부품에 적절한 레벨코드 접미사 부여
4. 엑셀 생성 규격에 맞춰 .xlsx 파일 생성
```

### 10.2 출력 시 지켜야 할 사항

```
필수:
  □ A열(레벨)은 반드시 L1부터 시작
  □ B열(품번)에는 레벨코드 접미사 [X] 포함
  □ 레벨 순서 규칙 준수 (1단계씩만 깊어짐)
  □ 파일 형식은 .xlsx

권장:
  □ 1행에 헤더 포함 (레벨, 품번, 품명, 규격, 수량, 단위, 비고)
  □ 수량이 1이 아닌 경우 반드시 E열에 명시
  □ 품명(C열)은 가능한 한 입력 (미등록 품번 자동 생성 시 사용됨)
  □ 외주 부품은 [O] 접미사 사용 (단위가 자동으로 LOT 설정)

주의:
  □ B열 품번에 앞뒤 공백 없이 정확하게 입력
  □ 동일 부모 아래 동일 자식 품번이 중복되지 않도록 주의
  □ 빈 행이 있으면 자동으로 건너뜀 (오류 아님)
```

### 10.3 레벨코드 접미사 부여 기준

```
제품/유닛/완성품            → [U] 또는 [F]
조립 키트/세트              → [K]
반제품/서브조합             → [S]
조합 부품                   → [C]
원자재/원부품 (가공 전)     → [R]
외주 가공품                 → [O]
자체 제조 가공품            → [M]
포장재/패키지               → [P]
```

### 10.4 출력 엑셀 템플릿

```
| 레벨 | 품번 | 품명 | 규격 | 수량 | 단위 | 비고 |
|------|------|------|------|------|------|------|
| L1   | {최상위 품번} [{레벨코드}] | {최상위 품명} | {규격} | 1 | EA | |
| L2   | {하위1 품번} [{레벨코드}]  | {하위1 품명}  | {규격} | {수량} | {단위} | |
| L3   | {하위2 품번} [{레벨코드}]  | {하위2 품명}  | {규격} | {수량} | {단위} | |
| ...  | ... | ... | ... | ... | ... | ... |
```
