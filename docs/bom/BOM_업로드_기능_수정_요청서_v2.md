## 1. 현재 문제

### 증상
- BOM 엑셀 업로드 시 **"레벨 점프: L0 → L2"** 오류 발생
- L1이 여러 개인 경우 처리 불가

### 원인
- L1을 만나도 새로운 BOM으로 인식하지 않음
- 전체 트리 구조 업로드 미지원

---

## 2. 요청 사항

### 2-1. 전체 BOM 트리 업로드 지원

**엑셀 구조 예시:**
```
L1  HXB15-PSD-B-O4-S1-D55 [U]     ← 유닛
L2    HXB15-PSD-B-STD [K]         ← 쉘 키트
L3      HB05-PLP-BBO-01-A6-HB [S] ← 서브어셈블리
L4        HB05-PLP-BBO-01-A6-HB [C] ← 부품
L5          HB05-PLP-BBO-01-A6-NN [R]
L5          PRCS-MNP-HBA-01-XX-NN [O]
L3      HB05-PLP-FSO-01-A6-HB [S]
L4        ...
L2    XBI15-O4-S1 [K]             ← 인서트 키트
L3      ...
L1  HXB15-PSD-B-O4-M1-D55 [U]     ← 새로운 BOM 시작
L2    ...
```

### 2-2. 레벨 점프 규칙

| 케이스 | 예시 | 처리 |
|--------|------|------|
| 한 단계 증가 | L2 → L3 | ✅ 정상 |
| 여러 단계 감소 | L5 → L2 | ✅ 정상 (상위로 복귀) |
| 여러 단계 증가 | L2 → L4 | ❌ 오류 (L3 누락) |
| L1 재등장 | L5 → L1 | ✅ 새 BOM 시작 |

### 2-3. 자동 전개 기능

**기존 BOM이 등록된 품번은 하위 구조 자동 연결**

```
[S]를 등록할 때:
L1  [S] 프론트쉘
L2    [C] HB05-PLP-FSO-01-A6-HB [C]  ← 품번만 적으면
L2    [R] 오링

시스템이 자동으로:
[C] HB05-PLP-FSO-01-A6-HB [C]
 ├─ [R] HB05-PLP-FSO-01-A6-NN [R]   ← 기존 BOM에서 자동 연결
 └─ [O] PRCS-MNP-HBA-01-XX-NN [O]   ← 기존 BOM에서 자동 연결
```

**장점:**
- 중복 작성 불필요
- 하위 BOM 수정 시 모든 곳에 자동 반영
- 품번 기준 참조로 데이터 일관성 유지

## 3. 처리 규칙

### 3-1. 같은 품번 재사용 / 기존 BOM 충돌

**→ 경고 후 덮어쓰기**

```
┌─────────────────────────────────────┐
│ ⚠️ 기존 BOM 덮어쓰기 경고              │
│                                     │
│ 다음 3건의 기존 BOM이 덮어씌워집니다:    │
│ - HB05-PLP-FSO-01-A6-HB [C]         │
│ - HB05-PLP-BBO-01-A6-HB [C]         │
│ - HB05-PLP-GHO-01-A6-HB [C]         │
│                                     │
│ [계속] [취소]                         │
└─────────────────────────────────────┘
```

### 3-2. 미등록 품번

**→ 미리보기에서 선택**

```
┌─────────────────────────────────────┐
│ ⚠️ 미등록 품번 2건 발견               │
│                                     │
│ ☑ HB01-XXX-YYY [R] - 자동 생성       │
│ ☑ PRCS-XXX-YYY [O] - 자동 생성       │
│                                     │
│ [전체 생성] [전체 스킵] [선택 적용]      │
└─────────────────────────────────────┘
```

**자동 생성 시 기본값:**
- 품명: 품번과 동일
- 단위: EA (공정은 LOT)
- 상태: ACTIVE
- 레벨: 품번 접미사에서 추출

### 3-3. 오류 시 트랜잭션

**→ 부분 성공**

- 오류 건만 스킵
- 나머지는 정상 처리
- 결과 리포트 제공

## 4. 업로드 흐름

```
1. 엑셀 파일 선택
        ↓
2. 파일 파싱 & 검증

   - 레벨 점프 체크
   - 순환 참조 체크
   - 품번 존재 여부 확인
   - 기존 BOM 충돌 확인
        ↓
3. 미리보기 화면
   ┌─────────────────────────────────────┐
   │ BOM 업로드 미리보기                    │
   │                                     │
   │ 전체: 45건                           │
   │ ✅ 정상: 40건                        │
   │ ⚠️ 기존 BOM 덮어쓰기: 3건             │
   │ ⚠️ 미등록 품번: 2건 [선택 필요]        │

   │ ✅ 업로드 완료                        │
   │                                     │
   │ 성공: 44건                           │
```

## 5. 엑셀 양식 (확정)

### 헤더 (1행)

| 컬럼 | 필수 | 설명 | 예시 |
|------|------|------|------|
| 레벨 | ✅ | L1, L2, L3... | L1 |
| 품번 | ✅ | 부품 코드 | HB05-PLP-FSO-01-A6-HB [C] |
| 품명 | ✅ | 부품 이름 | HXB15 플러그 프론트쉘... |
| 규격 | | 규격 (선택) | - |
| 수량 | ✅ | 필요 수량 | 1 |
| 단위 | ✅ | EA, LOT 등 | EA |
| 비고 | | 참고사항 | 외주 |

### 데이터 (2행부터)

```
레벨 | 품번                          | 품명                    | 규격 | 수량 | 단위 | 비고
L1   | HXB15-PSD-B-O4-S1-D55 [U]    | HXB15 플러그 유닛...     |      | 1    | EA   |
L2   | HXB15-PSD-B-STD [K]          | HXB15 쉘 키트...        |      | 1    | EA   |
L3   | HB05-PLP-FSO-01-A6-HB [S]    | HXB15 프론트쉘...       |      | 1    | EA   |
...
```

## 6. 검증 규칙

### 필수 검증

| 항목 | 검증 내용 | 오류 메시지 |
|------|----------|------------|
| 레벨 형식 | L + 숫자 | "잘못된 레벨 형식: {값}" |
| 레벨 시작 | L1으로 시작 | "L1(상위품번)이 먼저 필요합니다" |
| 레벨 점프 | 한 단계씩 증가 | "레벨 점프 불가: L{n} → L{m}" |
| 품번 필수 | 빈 값 불가 | "품번이 비어있습니다 (행 {n})" |
| 수량 필수 | 0 이상 숫자 | "수량이 올바르지 않습니다 (행 {n})" |
| 순환 참조 | A→B→A 불가 | "순환 참조 발견: {품번}" |

## 7. 구현 참고 (의사코드)

```javascript
function uploadBOM(excelData) {
    const parentStack = [];  // 부모 추적용 스택
    const results = { success: 0, skip: 0, error: 0 };
    
    for (const row of excelData) {
        const level = parseInt(row.level.replace('L', ''));
        
        // L1이면 새 BOM 시작
        if (level === 1) {
            parentStack.length = 0;  // 스택 초기화
            parentStack.push(row.partNumber);
            createNewBOM(row.partNumber);
            continue;
        }
        
        // 레벨 점프 체크
        const currentLevel = parentStack.length;
        if (level > currentLevel + 1) {
            results.error++;
            logError(`레벨 점프 불가: L${currentLevel} → L${level}`);
            continue;
        }
        
        // 스택 조정 (상위로 올라갈 때)
        while (parentStack.length >= level) {
            parentStack.pop();
        }
        
        // 현재 부모 확인
        const parent = parentStack[parentStack.length - 1];
        
        // BOM에 추가
        addChildToBOM(parent, row.partNumber, row.quantity);
        
        // 기존 BOM 있으면 자동 전개
        if (hasExistingBOM(row.partNumber)) {
            // 하위 구조 자동 연결 (재귀적으로 처리됨)
        }
        
        // 스택에 추가
        parentStack.push(row.partNumber);
        results.success++;
    }
    
    return results;
}
```

## 8. 테스트 케이스

### 정상 케이스

| # | 입력 | 기대 결과 |
|---|------|----------|
| 1 | L1 → L2 → L2 → L1 → L2 | BOM 2개 생성 |
| 2 | L1 → L2 → L3 → L3 → L2 | BOM 1개, 깊이 3 |
| 3 | L1 → L2 → L3 → L4 → L5 → L2 | BOM 1개, L5에서 L2로 복귀 |
| 4 | [C]에 기존 BOM 있음 | 하위 [R], [O] 자동 연결 |

### 오류 케이스

| # | 입력 | 기대 결과 |
|---|------|----------|
| 1 | L2로 시작 | 오류: "L1이 먼저 필요합니다" |
| 2 | L1 → L3 (L2 없이) | 오류: "레벨 점프 불가" |
| 3 | A → B → A (순환) | 오류: "순환 참조 발견" |
