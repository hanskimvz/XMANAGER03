# 전자결재 날짜 수정 도구 — 사용설명서

전자결재 문서의 날짜(상신/완료/결재선 처리시각/감사이력)를 DB에서 직접 고치는 독립 실행 도구입니다.
운영 웹앱과 별개로 동작하며, 어느 폴더에 두어도 됩니다.

> ⚠️ **주의**
> - 이 도구는 **정정 이력(approval_corrections)을 남기지 않고** 날짜를 바꿉니다. 되돌릴 수 없습니다.
> - **실행 전 DB를 반드시 백업**하세요.
> - 용도: **출시 전 초기/이관 데이터 정리**. 외부 제출용 기록을 사후에 만드는 용도로는 쓰지 마세요.
> - `db_config.ini` 에 DB 비밀번호가 평문으로 들어갑니다. **개인 PC 로컬**에만 두세요.

---

## 1. 실행 방법

1. `전자결재_날짜수정.bat` **더블클릭**
2. 창이 뜨면 왼쪽 목록에서 문서를 선택 → 오른쪽에서 날짜 수정 → 저장

처음 실행 시 `db_config.ini` 가 없으면 자동 생성되고 "확인 후 재실행" 안내가 뜹니다.

---

## 2. 사전 준비 (최초 1회)

### (1) 파이썬 + 패키지
`SQLAlchemy` 와 `psycopg2` 가 설치된 파이썬이 필요합니다. 둘 중 하나:

- **(권장) 백엔드 가상환경 사용** — 추가 설치 불필요
  `전자결재_날짜수정.bat` 을 메모장으로 열어 아래 줄의 `REM` 을 풀고 경로를 맞춥니다:
  ```bat
  set "PY=H:\...\X-MANAGER_R0.1\backend\.venv\Scripts\python.exe"
  ```
- **또는 시스템 파이썬에 직접 설치**
  ```
  pip install sqlalchemy psycopg2-binary
  ```

### (2) 접속 대상 DB
- `전자결재_날짜수정.bat` 안의 `set APP_ENV=development` 로 대상 선택
  - `development` = 개발 DB (xmanager_dev)
  - `production` = 운영 DB (xmanager)
- 접속 정보는 `db_config.ini` 의 `[database]` 에서 읽습니다. 필요 시 수정하세요.

## 3. 화면 구성 / 사용 흐름

```
[왼쪽] 문서 목록            [오른쪽] 편집기
 - 검색/상태 필터            - 문서 날짜 (생성/상신/완료)
 - 클릭하면 불러오기          - 결재선 처리시각
                            - 감사이력 행위시각
                            - [무결성 검사] [시간 동기화] [저장]
```

1. **문서 선택**: 왼쪽 목록에서 클릭 (검색칸·상태 드롭다운으로 좁히기 가능)
2. **날짜 수정**: 입력칸 옆 **📅** 클릭 → 달력에서 날짜·시각 선택 (직접 타이핑도 가능)
3. **🔗 시간 동기화**: 종속값(감사이력·완료시각)을 기준값에 자동으로 맞춤
4. **🔍 무결성 검사**(선택): 시간 정합성·순서 점검
5. **저장 (커밋)**: 변경 요약 확인 후 반영. **무결성 위반이 있으면 저장이 막힙니다.**

---

## 4. 입력값(독립) vs 종속값 — 아이콘

| 아이콘 | 의미 | 해당 칸 | 어떻게 정해지나 |
|---|---|---|---|
| **✏ (초록)** | 입력값(독립) | 생성 · 상신 · **결재선 처리시각** | 사용자가 직접 정함(기준) |
| **🔗 (파랑)** | 종속값(자동) | **완료** · **감사이력 전체** | 기준값을 따라감 → [시간 동기화]로 채움 |

**권장**: ✏ 입력칸만 고치고 → **🔗 시간 동기화** → 저장.

### 같아야 하는 짝 (무결성 규칙)
- 상신(drafted_at) = SUBMIT 감사이력
- 결재선 step.처리시각 = 같은 결재자의 APPROVE/REJECT 감사이력
- 완료(completed_at) = 최종 처리된 결재선
- 시간 순서: 생성 ≤ 상신 ≤ 1차결재 ≤ … ≤ 최종결재(=완료)

이 규칙을 어기면 저장이 차단되고 문제 목록이 표시됩니다.

## 6. (참고) 명령줄(CLI) 사용

GUI 없이 일괄/스크립트로 쓰려면:
```
python edit_approval_dates.py --doc AP-2026-0001                       # 현재 값 조회
python edit_approval_dates.py --doc AP-2026-0001 --drafted "2026-03-15 09:30" --line 1="2026-03-15 10:00"   # 미리보기
python edit_approval_dates.py --doc AP-2026-0001 --drafted "2026-03-15 09:30" --commit                      # 실제 반영
```

## 7. 문제 해결

| 증상 | 원인/해결 |
|---|---|
| `ModuleNotFoundError: sqlalchemy/psycopg2` | 2-(1) 참고 — 백엔드 .venv 경로 지정 또는 pip 설치 |
| `password authentication failed` | `db_config.ini` 접속정보 확인, `APP_ENV` 대상 확인 |
| 한글이 깨져 보임(콘솔) | GUI는 정상. 콘솔 출력만의 문제 |
| "DB 설정파일을 새로 만들었습니다" | 정상 — `db_config.ini` 확인 후 다시 실행 |
