## 2. 이번에 추가한 기능 (요청사항 전부)

| 요청 | 구현 |
|------|------|
| **파일 업로드** | 기안 작성/상세에서 첨부 업로드·목록·다운로드·삭제 (임시저장 후 첨부 활성화) |
| **일반 기안 + 프리폼 양식** | 일반 기안 + **구매/회의/출장/휴가** 4종. 양식 선택 시 "입력해야 할 항목"을 필드로 **가이드**(라벨·필수표시·도움말) |
| **프린트** | 상세화면 [인쇄] → 결재란+도장+본문 HTML 새 창 인쇄 (A4 `@media print`) |
| **참조(CC)** | 결재권 없이 열람만 가능한 수신자 지정 + **참조함** 탭 |
| **휴가 연차 계산** | 휴가 양식에서 기간→일수 자동계산(주말 제외, 반차 0.5) + "올해 N일 중 X 사용/잔여 Y" 표시, 승인 시 차감 |
| **관리자 전체검색·정정** | 관리(/admin) → "전자결재" 탭: 모든 결재 문서 검색(키워드/상태/기간) + 오류(날짜·내용·의견) 정정. 정정 시 **사유 필수**, 원본 변경분을 `approval_corrections`에 기록 + "관리자 정정됨" 표식(은폐 불가) |
| **버그 수정** | 상신 후 기안자 화면에서 문서 사라지던 문제 |

### 프리폼 양식별 가이드 필드
- **구매**: 품목·수량·단가·거래처·사유
- **회의록**: 일시·장소·참석자·안건·결정사항
- **출장**: 출장지·시작/종료일·목적·동행자·교통수단·예상경비
- **휴가**: 휴가유형·시작/종료일·일수(자동)·사유·대직자

## 4. 알려진 제약 / 남은 일

1. **PDF 다운로드**는 미동작 — WeasyPrint의 **GTK3 런타임이 이 PC에 미설치**. **인쇄(HTML)는 정상**이며 브라우저에서 "PDF로 저장"으로 대체 가능. 정식 PDF는 `backend/docs/PDF_SETUP.md`로 GTK 설치 후 활성화.

## 5. 환경 메모

- DB: native PostgreSQL 17, `xmanager_dev` (계정 `xmanager`/`xmanager1014`) — 빈 개발 DB(운영 데이터 없음, 결재 테스트 전용)
- 백엔드: `http://127.0.0.1:8001` (uvicorn, venv 재생성됨). API 문서 `/docs`
- 프론트: `http://localhost:5174` (Vite dev)
- 서버 재시작: `start-dev.bat` 또는 `backend`에서 `.venv\Scripts\activate` 후 `uvicorn app.main:app --port 8001`
- DB 복구가 필요하면 `reset-local-db.ps1`(관리자 PowerShell)
