# 구매 기안 절차 설명서 (구매기안서 → 지출결의서)

> 대상: 구매 담당자 · 대표(승인자) · 집행 담당(경영지원). 작성 2026-06-22 (v0.46.0).
> 전자결재 메뉴에서 진행합니다. 문의: 시스템 관리자.

---

## 1. 한눈에 보는 흐름

```
[구매 담당]                 [대표]              [구매 담당]                 [집행 담당(경영지원)]        [구매 담당]
구매기안서 작성·상신  ──▶  구매 승인   ──▶  (집행 시기 도래)        ──▶  지출결의서 승인           ──▶  완료 확인
(결제방법·집행조건 명시)                    지출결의서 작성·상신          = 집행 완료(시행일 입력)        (문서함에서)
       PR-2026-####                              PE-2026-####
```

- **2개의 문서**가 한 건의 구매를 이룹니다: **① 구매기안서(PR)** = "사도 되나" 승인, **② 지출결의서(PE)** = "이제 돈 내주세요" 집행.
- ②는 ①에 **연결**되어, ① 화면에서 집행 진행 상황을 바로 볼 수 있습니다.
- 한 건의 구매를 **나눠서 집행**(분할 지급)하려면 지출결의서를 여러 번 올리면 됩니다.

---

## 2. ① 구매기안서 작성 (구매 담당)

1. **전자결재 → 기안 작성 → 양식: "구매기안서"** 선택.
2. 항목 입력:
   - **품목 표**: **[+ 품목 추가]** 로 여러 품목을 행으로 입력(품목명/수량/단가). 행마다 금액이 자동 계산되고, **합계 금액은 자동**으로 채워집니다(직접 수정 불가).
     ```
     품목        수량   단가         금액
     노트북       2    1,500,000   3,000,000
     모니터       3      300,000     900,000
     ───────────────────────────── 합계 3,900,000
     ```
   - **거래처**
   - **결제방법**: `현금-선결제` / `익월결제` / `카드결제`
   - **집행조건**: `검수완료 후` / `선집행` / `익월` / `지정일` — 집행 담당이 *언제* 돈을 내줄지 판단하는 기준.
   - **집행 예정일**: 집행조건이 "지정일"일 때 날짜 입력(그 외 선택).
   - **사유**
3. **결재선**: 대표(승인자). (기본 결재자가 설정돼 있으면 자동으로 채워집니다.)
4. **상신**. → 대표가 승인하면 구매 자체는 확정.

> 💡 결제방법·집행조건을 적어두면 집행 담당이 **구매기안서만 보고** 언제·어떻게 집행할지 압니다.

---

## 3. ② 지출결의서 작성 = 집행 요청 (구매 담당)

자금 집행 시기가 되면(검수 완료 / 선집행 / 한 달 후 등) 구매 담당이 올립니다.

1. **승인된 구매기안서 상세 화면** → **"후속: 지출결의서 작성"** 버튼 클릭.
   - (또는 기안 작성에서 "지출결의서" 양식 선택 후 선행 구매기안서를 연결)
2. **거래처·금액·결제방법이 구매기안서에서 자동으로 채워집니다.** 필요 시 수정.
   - **집행 요청 사유/시점**: 예) "검수 완료, 집행 요청".
   - **실집행액**: 청구와 다르면 입력(미입력 시 청구 금액과 동일).
3. **결재선**: **집행 담당이 자동으로 채워집니다**(관리자가 지정해 둔 사람). 필요 시 추가/변경 가능.
4. **상신**. → 집행 담당에게 결재 대기로 넘어갑니다(= 집행 요청 완료).

> 🔧 **집행 담당 지정/변경(관리자)**: 관리 → 전자결재 → **"집행 담당 지정"** 에서 설정합니다. 여기서 지정한 사람(들)이 지출결의서 작성 시 결재선에 자동으로 들어갑니다(순서대로, 마지막 사람 승인=집행 완료). 미지정 시 작성자의 기본 결재자로 채워집니다.

---

## 4. ② 지출결의서 승인 = 집행 완료 (집행 담당)

1. 결재함에서 지출결의서 열기 → 내용·금액 확인.
2. **승인 버튼 옆 "시행일(집행일)" 날짜를 입력**한 뒤 **[집행 승인]**.
   - 시행일 = 실제로 자금을 집행한(또는 집행 예정) 날짜.
3. 승인하면 문서가 **승인완료(=집행 완료)** 되고, 시행일이 문서에 기록됩니다.

> 시행일을 비우고 승인하면 확인 메시지가 뜹니다(가능하면 입력 권장).

---

## 5. 완료 확인 (구매 담당)

- 지출결의서가 승인완료되면 **내 기안함**에서 상태로 확인됩니다.
- **구매기안서 상세 화면 "후속 문서"** 에 연결된 지출결의서와 **상태(승인완료=집행됨) + 시행일**이 표시됩니다.
- 분할 집행이면 여러 지출결의서가 각각의 상태로 함께 보입니다.

---

## 6. 문서번호 규칙
- 구매기안서: **PR-연도-일련번호** (예: PR-2026-0001)
- 지출결의서: **PE-연도-일련번호** (예: PE-2026-0001)

## 7. 자주 묻는 질문
- **Q. 지출결의서 없이 구매기안서만으로 집행하면 안 되나요?**
  A. 지출결의서는 자금 집행의 회계 증빙입니다. 집행은 반드시 지출결의서로 진행하세요.
- **Q. 결제방법/집행조건 항목을 회사에 맞게 바꾸고 싶어요.**
  A. 관리자가 양식 옵션을 조정할 수 있습니다(관리자에게 요청).
- **Q. 한 구매를 여러 번 나눠 집행할 수 있나요?**
  A. 네. 같은 구매기안서에서 지출결의서를 여러 번 올리면 됩니다.
- **Q. 집행 담당은 누구인가요? 바꿀 수 있나요?**
  A. **관리자가 "관리 → 전자결재 → 집행 담당 지정"에서 지정**합니다(보통 경영지원). 지정한 사람이 지출결의서 결재선에 자동으로 들어가며, 언제든 변경할 수 있습니다.
