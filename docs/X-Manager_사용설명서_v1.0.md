## 1. 시스템 개요

### 1.1 X-Manager란?

X-Manager는 제조업체를 위한 **부품 관리 시스템(PLM - Product Lifecycle Management)**입니다.

**주요 기능:**
- 부품 마스터 관리 (자동 품번 생성)
- BOM(Bill of Materials) 구성 관리
- 원가 계산 (BOM 기반, 이동평균법)
- 거래처 관리 (공급업체/고객사)
- 발주 및 입고 관리
- 작업지시서 관리
- 재고 관리 (로트 추적, FIFO)
- 파일 첨부 (도면, 사진, 문서)

### 1.2 시스템 요구사항

**권장 브라우저:**
- Google Chrome 90+
- Microsoft Edge 90+
- Mozilla Firefox 88+

**화면 해상도:**
- 최소: 1280 x 720
- 권장: 1920 x 1080

## 2. 시작하기

### 2.1 시스템 접속

1. 웹 브라우저를 실행합니다.
2. 주소창에 시스템 URL을 입력합니다.
   - 로컬: `http://localhost:5173`
   - 네트워크: `http://{서버IP}:5173`
3. 메인 화면이 표시됩니다.

## 3. 메인 화면 구성

### 3.1 공통 UI 요소

#### 검색 영역
```
┌─────────────────────────────────────────────────────────────┐
│  [검색어 입력]              [대분류 ▼] [상태 ▼]  [검색]     │
└─────────────────────────────────────────────────────────────┘
```

- **검색어 입력**: 품번, 부품명 등으로 검색
- **필터 드롭다운**: 분류별 필터링
- **검색 버튼**: 검색 실행 (Enter 키로도 가능)

#### 목록 테이블
```
┌─────┬───────────┬─────────┬────────┬─────────┬─────────┐
│  #  │   품번    │  부품명  │  분류  │  상태   │  작업   │
├─────┼───────────┼─────────┼────────┼─────────┼─────────┤
│  1  │ HB01-...  │ 하우징   │ HB01   │ 활성    │ [👁][✏][🗑] │
│  2  │ HB01-...  │ 커버     │ HB01   │ 활성    │ [👁][✏][🗑] │
└─────┴───────────┴─────────┴────────┴─────────┴─────────┘
```

- **컬럼 헤더 클릭**: 정렬 변경 (오름차순/내림차순)
- **작업 버튼**:
  - 👁 (눈): 상세 보기
  - ✏ (연필): 수정
  - 🗑 (휴지통): 삭제

#### 페이지네이션
```
[이전] [1] [2] [3] ... [10] [다음]    표시: [50 ▼] 건
```

- 페이지 번호 클릭으로 이동
- 표시 건수 변경 가능 (10/20/50/100)

### 3.2 토스트 알림

작업 결과가 화면 우상단에 토스트 형태로 표시됩니다.

| 색상 | 의미 |
|------|------|
| 녹색 | 성공 |
| 빨강 | 오류 |
| 노랑 | 경고 |
| 파랑 | 정보 |

## 4. 코드 마스터 관리

### 4.1 개요

코드 마스터는 부품 품번 생성 및 분류에 사용되는 기준 코드를 관리합니다.

**접속 경로**: 메뉴 > 코드 관리 또는 `/codes`

### 4.2 코드 종류

#### 품번 구성요소 (품번에 포함되는 코드)

| 코드 | 자릿수 | 설명 | 예시 |
|------|--------|------|------|
| 대분류 (ProductLine) | 4자리 | 제품 라인 구분 | HB01, BI03, TF01 |
| 소분류 (PartGroup) | 3자리 | 품목군 구분 | DCP, PLP, OCP |
| 재질 (Material) | 2자리 | 소재 구분 | A6, S4, XX |
| 후처리 (Treatment) | 2자리 | 표면처리 구분 | NK, NN, WA |

#### 분류 속성 (품번에 미포함, 검색/필터용)

| 코드 | 설명 | 다중선택 |
|------|------|----------|
| 개발구분 (DevelopmentType) | 개발/규격/상용 등 | X |
| 부품유형 (PartType) | 가공/고무/광학 등 | O |
| 도면여부 (DrawingType) | 도면/표준/없음 | X |
| 레벨 (Level) | BOM 레벨 (F/P/K/S/R) | X |

### 4.3 코드 등록 방법

1. 해당 코드 탭을 선택합니다.
2. **[+ 추가]** 버튼을 클릭합니다.
3. 필수 정보를 입력합니다:
   - **코드**: 고유 코드 (예: HB01)
   - **한글명**: 코드 설명 (예: HB 1호기)
   - **영문명**: 영문 설명 (선택)
4. **[저장]** 버튼을 클릭합니다.

### 4.4 품번 시뮬레이터

품번 구조를 미리 확인할 수 있는 기능입니다.

**접속 경로**: 코드 관리 > 품번 시뮬레이터 탭

```
품번 구조 (v1.1):
┌────────┬────────┬─────────┬────────┬────────┐
│ 대분류  │ 소분류  │ 품목코드 │  재질  │ 후처리  │
│  4자리  │  3자리  │  5자리   │ 2자리  │  2자리  │
├────────┼────────┼─────────┼────────┼────────┤
│  HB01  │  DCP   │  00001  │   A6   │   NK   │
└────────┴────────┴─────────┴────────┴────────┘

생성 품번: HB01-DCP-00001-A6-NK
```

## 5. 부품 마스터 관리

### 5.1 개요

부품의 기본 정보, 분류, 가격 정보 등을 관리합니다.

**접속 경로**: 메뉴 > 부품 관리 또는 `/parts`

### 5.2 부품 목록 조회

#### 검색 필터

| 필터 | 설명 |
|------|------|
| 검색어 | 품번, 부품명으로 검색 |
| 대분류 | 제품라인 필터 (HB01, BI03 등) |
| 소분류 | 품목군 필터 (DCP, PLP 등) |
| 레벨 | BOM 레벨 필터 (F, P, K 등) |
| 상태 | ACTIVE/INACTIVE/OBSOLETE |

#### 목록 컬럼

| 컬럼 | 설명 |
|------|------|
| 품번 | 시스템 생성 품번 |
| 품번(표시) | 하이픈 포함 표시용 품번 |
| 부품명 | 한글 부품명 |
| 대분류 | 제품라인 코드/명칭 |
| 규격 | 부품 규격 |
| 상태 | 활성/비활성/단종 |
| 등록일 | 부품 등록일자 |

### 5.3 부품 등록

1. **[+ 부품 등록]** 버튼을 클릭합니다.
2. 등록 모달이 열립니다.

#### 기본 정보 입력

```
┌─────────────────────────────────────────────────────────────┐
│                    부품 등록                                 │
├─────────────────────────────────────────────────────────────┤
│  부품명 *        [                              ]           │
│  영문명          [                              ]           │
│  규격            [                              ]           │
│  설명            [                              ]           │
├─────────────────────────────────────────────────────────────┤
│  품번 구성                                                   │
│  대분류 *        [HB01 - HB 1호기        ▼]                 │
│  소분류 *        [DCP - 절삭가공품       ▼]                 │
│  품목코드 *      [001] (3자리 입력, 뒤 2자리 자동생성)       │
│  재질            [A6 - 알루미늄 6061     ▼]                 │
│  후처리          [NK - 니켈도금          ▼]                 │
├─────────────────────────────────────────────────────────────┤
│  미리보기 품번: HB01-DCP-00101-A6-NK                        │
└─────────────────────────────────────────────────────────────┘
```

#### 필수 입력 항목

| 항목 | 설명 | 비고 |
|------|------|------|
| 부품명 | 한글 부품명 | 필수 |
| 대분류 | 제품라인 선택 | 필수 |
| 소분류 | 품목군 선택 | 필수 |
| 품목코드 | 앞 3자리 입력 | 필수, 뒤 2자리 자동생성 |

#### 선택 입력 항목

| 항목 | 설명 |
|------|------|
| 영문명 | 영문 부품명 |
| 규격 | 부품 규격/사양 |
| 재질 | 소재 코드 |
| 후처리 | 표면처리 코드 |
| 레벨 | BOM 레벨 |
| 설명 | 상세 설명 |

#### 분류 속성 입력

```
┌─────────────────────────────────────────────────────────────┐
│  분류 속성 (품번 미포함)                                     │
│  개발구분        [D - 개발품              ▼]                │
│  부품유형        [☑ P-가공] [☑ O-광학] [☐ E-고무]          │
│  도면여부        [D - 도면있음            ▼]                │
│  레벨            [R - 단품                ▼]                │
└─────────────────────────────────────────────────────────────┘
```

#### 가격 정보 입력 (v0.18.0+)

```
┌─────────────────────────────────────────────────────────────┐
│  가격 정보                                                   │
│  기준단가        [          ] [KRW ▼]  (수동 입력 단가)      │
│  가공비          [          ] [KRW ▼]  (노무비)              │
│  경비            [          ] [KRW ▼]  (간접비용)            │
├─────────────────────────────────────────────────────────────┤
│  공급업체        [ABC전자 - SUP001      ▼] [+ 간편등록]     │
│  리드타임        [  7  ] 일                                  │
│  최소주문수량    [  10 ] 개                                  │
└─────────────────────────────────────────────────────────────┘
```

3. **[저장]** 버튼을 클릭합니다.
4. 품번이 자동 생성되어 저장됩니다.

### 5.4 부품 수정

1. 목록에서 수정할 부품의 **[✏]** 버튼을 클릭합니다.
2. 수정 모달이 열립니다.
3. 필요한 항목을 수정합니다.

**품번 수정 옵션:**
- **품번 직접 수정**: 품번 필드에 직접 입력
- **품번 재생성**: "품번 재생성" 체크박스 선택 시 분류 변경에 따라 품번 자동 재생성

4. **[저장]** 버튼을 클릭합니다.

### 5.5 부품 삭제 (2단계 삭제)

X-Manager는 부품 삭제 시 2단계 삭제 정책을 적용합니다.

**1단계: 단종 처리**
- ACTIVE/INACTIVE 상태의 부품 삭제 시 → OBSOLETE(단종) 상태로 변경
- 데이터는 보존되며 목록에서 "단종" 표시

**2단계: 완전 삭제**
- OBSOLETE 상태의 부품 삭제 시 → DB에서 완전 삭제
- 연관 데이터(BOM, 재고 등) 사용 여부 확인 후 삭제

### 5.6 부품 상세 보기

1. 목록에서 **[👁]** 버튼을 클릭합니다.
2. 상세 모달이 탭 형태로 열립니다.

| 탭 | 내용 |
|---|------|
| 기본정보 | 품번, 부품명, 분류, 규격 등 |
| 가격정보 | 기준단가, 재고단가, 최근단가, 평균단가 |
| 파일 | 도면, 사진, 문서 첨부파일 |
| BOM | 해당 부품의 BOM 구성 |
| 이력 | 가격 변동 이력 |

### 5.7 조합/키트 등록

기존 품번 체계를 따르지 않는 조합품, 키트, 어셈블리를 등록합니다.

1. BOM 관리 화면에서 **[+ 조합/키트 등록]** 버튼을 클릭합니다.
2. 자유형식 품번을 직접 입력합니다.

```
┌─────────────────────────────────────────────────────────────┐
│  조합/키트 등록 (자유형식 코드)                              │
├─────────────────────────────────────────────────────────────┤
│  품번 *          [CONNECTOR-KIT-001           ]            │
│  품명 *          [커넥터 키트 세트             ]            │
│  레벨 *          [K - 키트                 ▼]              │
│  설명            [8핀 커넥터 + 케이블 + 커버 세트]          │
└─────────────────────────────────────────────────────────────┘
```

## 6. BOM 관리

### 6.1 개요

BOM(Bill of Materials)은 제품을 구성하는 부품의 계층 구조를 관리합니다.

**접속 경로**: 메뉴 > BOM 관리 또는 `/bom`

### 6.2 화면 구성

```
┌─────────────────────────────────────────────────────────────┐
│  BOM 관리                                                    │
├──────────────────────────┬──────────────────────────────────┤
│  [상위 부품 선택 영역]     │  [BOM 구성 영역]                  │
│                          │                                  │
│  검색: [           ]     │  상위부품: HB01-DCP-00001-A6-NK  │
│  [부품 목록 표시]         │  (하우징 어셈블리)                │
│                          │                                  │
│  > HB01-DCP-00001 선택   │  ┌─ 하위부품 목록 ─────────────┐ │
│    HB01-DCP-00002        │  │ 1. 하우징본체   x 1         │ │
│    HB01-DCP-00003        │  │ 2. 커버        x 1         │ │
│                          │  │ 3. 볼트 M4     x 4         │ │
│                          │  └───────────────────────────┘ │
│                          │                                  │
│                          │  [+ 부품 추가] [트리 보기]        │
└──────────────────────────┴──────────────────────────────────┘
```

### 6.3 상위 부품 선택

1. 좌측 영역에서 검색어를 입력하거나 필터를 선택합니다.
2. 부품 목록에서 BOM을 구성할 상위 부품을 클릭합니다.
3. 우측에 해당 부품의 BOM 구성이 표시됩니다.

### 6.4 하위 부품 추가

#### 단일 추가
1. **[+ 부품 추가]** 버튼을 클릭합니다.
2. 부품 검색 후 선택합니다.
3. 수량을 입력합니다.
4. **[추가]** 버튼을 클릭합니다.

#### 다중 추가
1. **[+ 다중 추가]** 버튼을 클릭합니다.
2. 부품 검색 모달이 열립니다.
3. 체크박스로 여러 부품을 선택합니다.
4. **[선택 완료]** 버튼을 클릭합니다.
5. 각 부품의 수량을 입력합니다.

### 6.5 BOM 트리 보기

계층 구조를 트리 형태로 시각화합니다.

```
HB01-DCP-00001 (하우징 어셈블리)
├── HB01-DCP-00010 (하우징 본체) × 1
│   ├── HB01-DCP-00011 (내부 프레임) × 1
│   └── HB01-DCP-00012 (실링 가스켓) × 2
├── HB01-DCP-00020 (커버) × 1
└── HB01-DCP-00030 (볼트 M4) × 4
```

- **[+]** 클릭: 하위 펼치기
- **[-]** 클릭: 하위 접기
- **[전체 펼침]**: 모든 레벨 펼치기
- **[전체 접기]**: 모든 레벨 접기

### 6.6 BOM 수정/삭제

#### 수량 수정
1. BOM 목록에서 수량 셀을 클릭합니다.
2. 새 수량을 입력합니다.
3. Enter 키 또는 다른 영역 클릭으로 저장됩니다.

#### 순서 변경
- 드래그 앤 드롭으로 순서를 변경합니다.
- 변경된 순서는 자동 저장됩니다.

#### 삭제
1. 삭제할 BOM 항목의 **[🗑]** 버튼을 클릭합니다.
2. 확인 메시지에서 **[삭제]**를 클릭합니다.

### 6.7 BOM 레벨 체계

| 레벨 | 코드 | 설명 |
|------|------|------|
| 완제품 | F | Finished Goods - 최종 제품 |
| 패키지 | P | Package - 포장 단위 |
| 키트 | K | Kit - 키트 구성품 |
| 서브어셈블리 | S | Sub-Assembly - 반제품 |
| 단품 | R | Raw Material/Part - 원자재/단품 |

### 6.8 순환 참조 방지

시스템은 순환 참조를 자동으로 감지하고 방지합니다.

**순환 참조 예시:**
```
A → B → C → A  (불가능)
```

순환 참조가 감지되면 오류 메시지가 표시되고 저장이 거부됩니다.

## 7. 원가 관리

### 7.1 개요

부품의 다양한 원가 정보를 관리하고 BOM 기반 원가를 계산합니다.

### 7.2 단가 종류

| 단가 유형 | 설명 | 산출 방식 |
|-----------|------|-----------|
| 기준단가 | 목표/표준 단가 | 수동 입력 |
| 재고단가 | 재고 평가 단가 | 이동평균법 자동 계산 |
| 최근단가 | 마지막 입고 단가 | 입고 시 자동 갱신 |
| 평균단가 (30일) | 최근 30일 평균 | 자동 계산 |
| 평균단가 (90일) | 최근 90일 평균 | 자동 계산 |
| 평균단가 (5건) | 최근 5건 평균 | 자동 계산 |
| 평균단가 (10건) | 최근 10건 평균 | 자동 계산 |

### 7.3 기준단가 설정

1. 부품 상세 보기에서 **가격정보** 탭을 선택합니다.
2. 기준단가 필드에 금액을 입력합니다.
3. 통화를 선택합니다 (KRW, USD, EUR, JPY, CNY).
4. **[저장]** 버튼을 클릭합니다.

### 7.4 BOM 기반 원가 계산

조립품의 원가를 하위 부품 기준으로 자동 계산합니다.

**계산 공식:**
```
총원가 = 재료비 + 가공비 + 경비

재료비 = Σ(하위부품 단가 × 수량)
```

**계산 방법:**
1. BOM 관리 화면에서 상위 부품을 선택합니다.
2. **[원가 계산]** 버튼을 클릭합니다.
3. 계산 결과가 표시됩니다:

```
┌─────────────────────────────────────────────────────────────┐
│  BOM 원가 계산 결과                                          │
├─────────────────────────────────────────────────────────────┤
│  부품: HB01-DCP-00001 (하우징 어셈블리)                      │
│                                                             │
│  ┌─ 원가 구성 ──────────────────────────────────────────┐  │
│  │  재료비      12,500원  (하위부품 합산)                │  │
│  │  가공비       3,000원  (수동 입력)                    │  │
│  │  경비         1,500원  (수동 입력)                    │  │
│  ├──────────────────────────────────────────────────────┤  │
│  │  총원가      17,000원                                 │  │
│  └──────────────────────────────────────────────────────┘  │
│                                                             │
│  ┌─ BOM 구성품 상세 ────────────────────────────────────┐  │
│  │  품번              품명        수량   단가     금액   │  │
│  │  HB01-DCP-00010   하우징본체    1   8,000   8,000    │  │
│  │  HB01-DCP-00020   커버          1   3,500   3,500    │  │
│  │  HB01-DCP-00030   볼트 M4       4     250   1,000    │  │
│  └──────────────────────────────────────────────────────┘  │
│                                                             │
│  [원가 저장] [전체 재계산] [닫기]                            │
└─────────────────────────────────────────────────────────────┘
```

4. **[원가 저장]** 버튼으로 계산된 원가를 부품에 저장합니다.

### 7.5 단가 우선순위

단품(BOM 없음)의 단가 결정 우선순위:

```
1순위: 기준단가 (standard_price)
   ↓ (없으면)
2순위: 최근단가 (latest_price)
   ↓ (없으면)
3순위: 재고단가 (inventory_avg_price)
```

### 7.6 재고단가 계산 (이동평균법)

입고 시 재고단가가 자동으로 재계산됩니다.

**계산 공식:**
```
신규 재고단가 = (기존 재고금액 + 신규 입고금액) / 총 수량
```

**예시:**
```
기존 재고: 100개 × 1,000원 = 100,000원
신규 입고:  50개 × 1,200원 =  60,000원
─────────────────────────────────────
총 수량: 150개
총 금액: 160,000원
신규 재고단가: 160,000원 / 150개 = 1,066.67원
```

### 7.7 환율 관리

외화 단가를 원화로 자동 환산합니다.

**지원 통화:**
- KRW (원화)
- USD (미국 달러)
- EUR (유로)
- JPY (일본 엔)
- CNY (중국 위안)

**환율 등록:**
1. 시스템 관리에서 환율 등록 화면을 엽니다.
2. 통화 코드와 환율을 입력합니다.
3. 적용 시작일을 지정합니다.

### 7.8 가격 이력 조회

부품의 모든 가격 변동 이력을 조회합니다.

1. 부품 상세 보기 > **이력** 탭을 선택합니다.
2. 가격 이력 목록이 표시됩니다:

| 일자 | 유형 | 단가 | 통화 | 공급업체 | 참조문서 |
|------|------|------|------|----------|----------|
| 2026-01-20 | PURCHASE | 1,200 | KRW | ABC전자 | PO-2026-0001 |
| 2026-01-15 | STANDARD | 1,000 | KRW | - | 기준단가 변경 |
| 2026-01-10 | PURCHASE | 1,100 | KRW | XYZ산업 | PO-2025-0050 |

**가격 유형:**
- PURCHASE: 구매 단가 (발주/입고 시)
- STANDARD: 기준단가 변경
- MANUAL: 수동 입력
- QUOTE: 견적가

## 9. 발주 관리

### 9.1 개요

공급업체에 대한 부품 발주를 생성하고 관리합니다.

**접속 경로**: 메뉴 > 발주 관리 또는 `/purchase-orders`

### 9.2 발주서 상태

```
DRAFT → CONFIRMED → ORDERED → RECEIVED → (CANCELLED)
 작성      확정       발주      입고완료     취소
```

| 상태 | 설명 | 가능한 작업 |
|------|------|-------------|
| DRAFT | 작성 중 | 수정, 삭제, 확정 |
| CONFIRMED | 확정됨 | 발주, 취소 |
| ORDERED | 발주완료 | 입고처리, 취소 |
| RECEIVED | 입고완료 | - |
| CANCELLED | 취소됨 | 복원 |

### 9.3 발주서 생성

1. **[+ 발주서 작성]** 버튼을 클릭합니다.
2. 기본 정보를 입력합니다:

```
┌─────────────────────────────────────────────────────────────┐
│  발주서 작성                                                 │
├─────────────────────────────────────────────────────────────┤
│  발주번호        [PO-2026-0001        ] (자동생성)          │
│  공급업체 *      [ABC전자              ▼]                   │
│  발주일 *        [2026-01-20          📅]                   │
│  납기예정일 *    [2026-01-27          📅]                   │
│  비고            [                              ]           │
├─────────────────────────────────────────────────────────────┤
│  발주 품목                                                   │
│  [+ 품목 추가]                                              │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ 품번          품명        수량    단가      금액    │   │
│  │ HB01-...     하우징       100   1,000   100,000    │   │
│  │ HB01-...     커버          50   2,000   100,000    │   │
│  └─────────────────────────────────────────────────────┘   │
│                                    합계:    200,000원       │
└─────────────────────────────────────────────────────────────┘
```

3. **[저장]** 버튼을 클릭합니다 (DRAFT 상태로 저장).

### 9.4 발주 품목 추가

1. **[+ 품목 추가]** 버튼을 클릭합니다.
2. 부품 검색 후 선택합니다.
3. 수량과 단가를 입력합니다.
4. **[추가]** 버튼을 클릭합니다.

### 9.5 발주 진행

```
[확정] → [발주] → [입고처리]
```

**확정:**
- DRAFT → CONFIRMED 상태 변경
- 더 이상 품목 수정 불가

**발주:**
- CONFIRMED → ORDERED 상태 변경
- 공급업체에 발주 전달

**입고처리:**
- ORDERED → RECEIVED 상태 변경
- 재고에 자동 반영
- 가격 이력 자동 기록

### 9.6 결제 관리

발주서별 결제 상태를 관리합니다.

1. 발주 목록에서 **결제** 컬럼의 체크박스를 클릭합니다.
2. 결제 완료로 표시됩니다.
3. 결제일자가 자동으로 기록됩니다.

### 9.7 발주 롤백

입고완료 상태에서 이전 상태로 되돌립니다.

1. 발주서 상세에서 **[롤백]** 버튼을 클릭합니다.
2. RECEIVED → ORDERED 상태로 변경됩니다.
3. 재고에서 해당 수량이 차감됩니다.

## 10. 작업지시서 관리

### 10.1 개요

생산 작업을 지시하고 관리합니다.

**접속 경로**: 메뉴 > 작업지시서 또는 `/work-orders`

### 10.2 작업지시서 상태

```
DRAFT → APPROVED → ISSUED → IN_PROGRESS → COMPLETED → (CANCELLED)
 작성     승인      출고       진행중        완료        취소
```

| 상태 | 설명 |
|------|------|
| DRAFT | 작성 중 |
| APPROVED | 승인됨, 출고 대기 |
| ISSUED | 자재 출고완료 |
| IN_PROGRESS | 작업 진행 중 |
| COMPLETED | 작업 완료 |
| CANCELLED | 취소됨 |

### 10.3 작업지시서 생성

1. **[+ 작업지시서 작성]** 버튼을 클릭합니다.
2. 기본 정보를 입력합니다:

```
┌─────────────────────────────────────────────────────────────┐
│  작업지시서 작성                                             │
├─────────────────────────────────────────────────────────────┤
│  지시번호        [WO-2026-0001        ] (자동생성)          │
│  생산품목 *      [HB01-DCP-00001      ▼] 하우징 어셈블리    │
│  생산수량 *      [  100  ]                                   │
│  시작예정일 *    [2026-01-21          📅]                   │
│  완료예정일 *    [2026-01-25          📅]                   │
├─────────────────────────────────────────────────────────────┤
│  BOM 자동 전개   [☑] (승인 시 BOM 기준으로 소요량 계산)      │
└─────────────────────────────────────────────────────────────┘
```

3. **[저장]** 버튼을 클릭합니다.

### 10.4 가용 수량 확인

작업 전 BOM 기반 생산 가능 수량을 확인합니다.

1. **[가용수량 확인]** 버튼을 클릭합니다.
2. 결과가 표시됩니다:

```
┌─────────────────────────────────────────────────────────────┐
│  생산 가용수량 확인                                          │
├─────────────────────────────────────────────────────────────┤
│  생산품목: HB01-DCP-00001 (하우징 어셈블리)                  │
│  요청수량: 100개                                             │
│  최대생산가능: 85개                                          │
├─────────────────────────────────────────────────────────────┤
│  제한 부품 목록:                                             │
│  품번            품명        필요    재고    부족           │
│  HB01-DCP-00010  하우징본체   100     85     15            │
│  HB01-DCP-00030  볼트 M4      400    350     50            │
└─────────────────────────────────────────────────────────────┘
```

### 10.5 자재 출고 (FIFO)

승인된 작업지시서의 자재를 출고합니다.

**자동 출고:**
- 시스템이 FIFO(선입선출) 방식으로 로트 자동 선택
- 가장 오래된 로트부터 순차적으로 출고

**수동 로트 선택:**
1. 출고 모달에서 **[로트 직접 선택]**을 클릭합니다.
2. 원하는 로트와 수량을 지정합니다.
3. **[출고 확인]** 버튼을 클릭합니다.

### 10.6 작업지시서 취소/복원

**취소:**
1. 작업지시서의 **[취소]** 버튼을 클릭합니다.
2. CANCELLED 상태로 변경됩니다.
3. 출고된 자재가 있으면 재고로 복원됩니다.

**복원:**
1. 취소된 작업지시서의 **[복원]** 버튼을 클릭합니다.
2. 이전 상태로 복원됩니다 (출고 상태였으면 APPROVED로 복원).

### 10.7 2단계 삭제

- **1단계**: 취소 처리 (CANCELLED)
- **2단계**: 취소된 지시서만 완전 삭제 가능

## 11. 재고 관리

### 11.1 개요

부품별 재고 현황을 조회하고 관리합니다.

**접속 경로**: 메뉴 > 재고 관리 또는 `/inventory`

### 11.2 재고 현황 조회

| 컬럼 | 설명 |
|------|------|
| 품번 | 부품 품번 |
| 부품명 | 한글 부품명 |
| 현재고 | 실제 보유 수량 |
| 예약수량 | 작업지시 예약 수량 |
| 가용수량 | 현재고 - 예약수량 |
| 재고단가 | 이동평균 단가 |
| 재고금액 | 현재고 × 재고단가 |
| 상태 | NORMAL/LOW/OUT_OF_STOCK |

### 11.3 재고 상태

| 상태 | 조건 | 색상 표시 |
|------|------|----------|
| NORMAL | 재고 >= 재주문점 | 녹색 |
| LOW | 0 < 재고 < 재주문점 | 노랑 |
| OUT_OF_STOCK | 재고 = 0 | 빨강 |

### 11.4 로트 추적

발주 입고 시 자동으로 로트가 생성됩니다.

**로트 정보:**
- 로트번호: LOT-년월일-시퀀스
- 입고일
- 수량
- 단가
- 공급업체
- 참조문서 (발주번호)

**로트 조회:**
1. 재고 목록에서 부품을 클릭합니다.
2. **로트 현황** 탭에서 해당 부품의 로트 목록을 확인합니다.

### 11.5 재고 조정

실사 결과 등으로 재고를 직접 조정합니다.

1. 재고 목록에서 **[재고 조정]** 버튼을 클릭합니다.
2. 조정 유형을 선택합니다:
   - **증가**: 재고 추가
   - **감소**: 재고 차감
   - **설정**: 수량 직접 설정
3. 수량과 사유를 입력합니다.
4. **[확인]** 버튼을 클릭합니다.

## 14. 자주 묻는 질문

### Q1. 품번이 중복되었다고 나옵니다.

**A**: 품번은 시스템 전체에서 고유해야 합니다. 다음을 확인하세요:
- 동일한 대분류 + 소분류 + 품목코드 조합이 있는지 확인
- 품목코드 앞 3자리를 다른 값으로 변경

### Q2. BOM에서 부품을 추가할 수 없습니다.

**A**: 다음 경우 BOM 추가가 제한됩니다:
- 순환 참조가 발생하는 경우 (A→B→C→A)
- 이미 동일한 하위부품이 등록된 경우
- 상위부품과 하위부품이 동일한 경우

### Q3. 재고단가가 자동으로 바뀌었습니다.

**A**: 재고단가는 이동평균법으로 자동 계산됩니다.
- 발주 입고 시 재계산됨
- 수동으로 변경하려면 기준단가를 사용하세요

### Q4. 삭제한 부품을 복구하고 싶습니다.

**A**: 부품 삭제는 2단계로 진행됩니다:
- 1단계 삭제(단종)된 부품: 상태 필터에서 "단종" 선택 후 상태 변경 가능
- 2단계 완전 삭제된 부품: 복구 불가

### Q5. 발주서 입고처리를 취소하고 싶습니다.

**A**: 발주서 상세에서 **[롤백]** 버튼을 사용하세요.
- RECEIVED → ORDERED 상태로 변경
- 입고된 재고가 자동으로 차감됩니다

### Q6. 작업지시서 출고를 취소하고 싶습니다.

**A**: 작업지시서를 취소하면 출고된 자재가 재고로 복원됩니다.
- **[취소]** 버튼 클릭 → 재고 자동 복원
- 필요시 **[복원]** 버튼으로 이전 상태로 되돌리기

### Q7. 파일 업로드가 실패합니다.

**A**: 다음을 확인하세요:
- 파일 크기가 제한을 초과하지 않는지 (유형별 상이)
- 허용된 확장자인지
- 파일명에 특수문자가 없는지

### Q8. 원가 계산 결과가 0원입니다.

**A**: 하위 부품에 단가 정보가 없으면 0원으로 계산됩니다.
- 각 하위 부품의 기준단가 또는 최근단가를 입력하세요
- 또는 해당 부품의 발주 입고 이력이 있어야 합니다

### Q9. 특정 공급업체의 입고 이력만 보고 싶습니다.

**A**: 부품 상세 > 이력 탭에서 공급업체 필터를 사용하세요.
- 평균단가 계산 시에도 특정 공급업체만 필터링 가능

### Q10. 시스템 접속이 안 됩니다.

**A**: 다음을 확인하세요:
1. 백엔드 서버 실행 여부 (http://localhost:8000/docs)
2. 프론트엔드 서버 실행 여부 (http://localhost:5173)
3. 방화벽 설정 (5173, 8000 포트 허용)
4. 네트워크 연결 상태
