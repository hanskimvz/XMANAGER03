## 1. 파일 개요

- 시트 3개 (모두 visible, 보호 없음)
  - `조립체 견적 산출` — **메인 견적기** (A2:O64)
  - `커넥터 원가` — 커넥터 원가표(=Price List, 2023.12.14, "바이어 제공 표") — 참조용
  - `Cable & 조립비_가격산출` — 케이블/조립비 단가 계산 헬퍼

- 셀 주석 1개(C5, 작성자 XBT): "Assembly Order 코드에 사용되는 Cable 명 참조"
- 외부링크 1개: 케이블 원가 리스트(→ §6)

## 2. 메인 시트 데이터 흐름

```
[사람이 입력하는 것]                    [자동 계산]
 B: 품명(HXB13AS-PSD-B-O4-M3-D55-LC-…)  ─┐
 C: 미터수                                │  코드 파싱(사이즈/채널/모드/SA)
 D: 수량                                  │      │
 K: 기타비용(선택)                        │      ▼
                                          │   커넥터B = 채널수 × $1.5
 [백데이터 영역, 행 23~35]                 │   케이블  = 미터수 × 미터당단가(모드·채널별)
 C열: 커넥터 원가 (수기 입력) ★            │   조립비  = 채널수 + EBC단수(SA여부)별 고정표
 D열: 마진율   (수기 선택) ★              │      │
        │ E = 원가/(1−마진)               │      ▼
        │ F = E / 1,100 (=$)  ───────────►│  커넥터A = F(백데이터의 $값)
                                          ▼
                        합계$ = 커넥터A + 커넥터B + 케이블 + 조립비 + 기타
                                          ▼
                        최종단가 = ROUNDUP(합계, 0)   ← ★ ×1.3 없음
                                          ▼
                        소계 = 최종단가 × 수량
```

★ = 사람 손이 들어가는 지점.

## 3. 구성요소별 산출 로직 (정확한 규칙)

| 요소 | 셀/수식 요지 | 규칙 |
|---|---|---|
| **커넥터A** | `=F23` (백데이터 $값) | 원가 ÷ (1−마진) ÷ 1,100. **원가·마진은 수기.** |
| **커넥터B** | `=IF("SA"∈품명, 커넥터A, $F$37×채널수)` | SA(양단동일)면 A와 동일, 아니면 **채널수 × $1.5**(LC/SC 종단) |
| **케이블** | `=미터수 × I52` | 미터당 단가 CHOOSE: SM2/4ch $2.55, M3 2/4ch $2.89, SM6/8ch $4.22, M3 6/8ch $5.48 (=원화 2,800/3,180/4,640/6,032 ÷1,100) |
| **조립비** | 채널·SA로 L39:L46 조회 | 2ch $65(1단)/$76(2단), 4ch $98/$109, 6ch $131/$142, 8ch $164/$175. SA=2단, 그 외 1단 |
| **기타비용** | 수기 | 담당자 입력 (예: LC/SC/PC 추가 등) |

코드 파싱: `채널수 = RIGHT("O4",1)=4`, `모드 = LEFT("M3",1)=M`, `SA/O2/O4/O6/O8`은 `SEARCH()`로 판별.

## 4. 참고 시트 ①: `커넥터 원가` — = HXB 커넥터 Price List (검증됨)

- 제목은 "PRICE LIST / 바이어 제공 표(2023.12.14)"이나, 이 파일에선 **원가 기준표로** 쓰인다.
- 구성: HXB11/13/15 × 형태(PSD/RJ·RQ의 S/N/L) × O2~O6 × SM/MM. 값은 원화.
- 6채널 열은 일부 `=상위셀-300/-800` 수식(신규가 반영), 나머진 하드코딩.
- **✅ 대조 검증(2026-08-07):** 이 시트는 `견적/HXB 커넥터 Price List.xlsx`의 원가(K~P열)와 **값이 완전히 동일**(HXB13·15 전항목 일치, HXB11도 값 일치, **드리프트 0건**). 차이는 라벨링 방식뿐:
  - Price List = 설명체("Receptacle, Jam nut, Standard", "2Core SM")
  - 이 시트 = **주문코드체(RJS/RJN/RJL/RQS/RQN/RQL, O2-S/O2-M/…)** — 품명 파싱과 맞물리도록 relabel한 것. (N 변형은 S값 복제)

### ⚠️ 핵심: 커넥터 원가가 3벌로 존재 (수기 유지 → 드리프트 리스크)
```
① HXB 커넥터 Price List.xlsx (원가 K~P)   ← 진짜 마스터
      │ 사람이 복사·relabel
② 미화 파일 '커넥터 원가' 시트             ← 사본 (현재 일치)
      │ 사람이 눈으로 찾아 타이핑
③ 미화 파일 백데이터 C열(원가)             ← 수기 재입력 = 케바케 진원지
```
①이 바뀌어도 ②③은 자동으로 따라오지 않는다. → **커넥터 원가는 Price List 하나를 단일 마스터로 두고 견적기가 품명으로 자동 조회(VLOOKUP류)하게 만들면 ②③ 소멸 + 케바케 제거.** (케이블 원가의 "단일 마스터 승격"과 동일 패턴)

## 5. 참고 시트 ②: `Cable & 조립비_가격산출`

- **케이블 단독가 계산기:** 판매단가 = (보간마진 + 1) × 매입가
  - 보간마진 = 길이(500m~5,000m) 사이 선형보간. 케이블 종류(분류코드 GOC=2 / BRU=3)별로 다른 마진열 사용 (GOC ≈100→90%, BRU ≈30→25%).
  - 예: GOC SCC4D55, 600m → 마진 0.998 → 1,598.8/m
- **조립비 계산기:** 쉘조립(10,000) + 종단비(5,000×채널×2) + 검사비(5,000×채널) + 기타 → 합계 ×1.1(합계1) 또는 ×1.2(합계2)
- 이 시트는 **메인 견적기와 연결돼 있지 않다** (병렬 참고용). 메인은 자체 고정표를 씀 → 값이 갈라질 수 있음(리스크).

## 7. 미화 vs 원화 차이 (의도 확인됨)

- 미화: 합계 → 올림. 원화: 합계 → **×1.3** → 올림.
- ×1.3은 **국내 시장가 형성 + 국내 소량·단발 보정용 임시 장치**(사용자 확인). 버그 아님.
- 단, 이미 마진 60% 붙은 커넥터에도 재차 곱해지는 투박한 방식이라 향후 명시 규칙으로 대체 대상.

## 8. 재설계 기획에 주는 시사점

1. **케바케의 실체 = 백데이터 C·D열 수기 입력.** 커넥터 원가 자동조회(VLOOKUP/함수) + 마진율 규칙화만 해도 표준화 대부분 달성.
2. **입력 가드레일 필요.** 품명 형식·채널·모드 드롭다운/검증 → 신입 온보딩 목표에 직결.
3. **케이블 로직 일원화.** 메인 고정표 vs 헬퍼 보간식 중 기준 하나로 통일.
4. **외부·개인 PC 의존 제거.** 케이블 원가 마스터를 공용화하고 견적기가 이를 참조.
5. **원화/미화 일원화.** 통화·프리미엄을 파라미터로 → 한 로직에서 두 견적 산출, ×1.3의 명시적 대체.
6. **자산은 살리기.** 코드 파싱·채널/모드 판별·조립비 표는 잘 만들어져 있음 — 재설계 시 재활용.
