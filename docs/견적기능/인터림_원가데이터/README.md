## 계산에서 쓰는 법 (사양서 §6)

```
오더코드 HXB13-RJS-B-O4-S1-D55  →  파싱(size=HXB13, form=RJS, core=O4, mode=S)
  → A표 조회: cost_krw = 103,075
  → 커넥터A 판매 = 103,075 / (1 − 마진율)
  + 커넥터B = 채널수 × 1,500        (D표)

```

## ⚠️ 주의·확인사항 (데이터 신뢰도)

1. **A표 `form` 코드:** PSD(Plug)/RJS/RJN/RJL(Recep Jam: Std/N/Low)/RQS/RQN/RQL(Recep Flange). **RJN=RJS, RQN=RQS 값 동일**(N=복제행). HXB13·HXB11은 O2·O4만(O6 없음).
2. **HXB11 D55/S20 미세차이:** 원본에 무라벨 4행(D55 변형, 예 80,892)을 skip하고 **S20 변형(82,192) 사용**. 부츠 무관 규칙과 HXB11에서 ~1.6% 차이 → **확인 필요**.
3. **SUS표는 2022.05 구버전 + 중복행 다수** → dedup 필요. 재질 `B`(Al)/`S3`(SUS303)/`S6`(SUS316), 값은 **쉘(shell) 원가 only**(전체 커넥터 아님). SUS 옵션 델타 = `SUS쉘 − Al쉘`(예 HXB13-PSD: 55,140−21,310=33,830). **최신 단가는 2025 PDF**(`원가 확인용 참고자료 모음/스테인레스 쉘 가공비/*.pdf`) — 반영 시 교체.
4. **규칙은 데이터가 아님:** 마진(모델C)·국내프리미엄(×1.3)·환율(1,100)·가격인상률(품목별 비율)·합의가 우선순위는 사양서에 정의. 여기 CSV는 **원가·단가 기준값만**.
5. **통화:** A/SUS는 ₩, B/C/D는 ₩·$ 병기(옵션 B=통화별 표 유지).
