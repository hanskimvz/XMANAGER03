## 결론

1. **추출·계산 정확성 검증 완료:** CSV(A~D) + 사양서 규칙이 엑셀 산출값을 **4/4 완전 재현**. 데이터·파이프라인 신뢰.
2. **표준화로 인한 차이 = 마진 정책에서만 발생:**
   - 2채널: 0% (모델 C 기준 60% = 과거 60%)
   - 4채널: **−7.5% (개당 ≈ −36,000원)** — 모델 C 4ch **55%** vs 과거 실제 **60%**.
3. **성격:** 데이터 오류 아님. 과거 4ch는 가이드(54~56%)를 넘는 60% = 케바케. 모델 C가 55%로 표준화 → 하향. 특정 고객 유지 필요 시 **고객 델타 +5%p**로 60% 복원.
