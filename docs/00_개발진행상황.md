##### 원가관리 핵심 기능 (v0.18.0)
- [x] **부품 원가 정보 확장**
  - Parts 모델에 원가 관련 필드 대폭 추가:

    - `avg_price_30d`, `avg_price_90d`, `avg_price_last5`, `avg_price_last10`: 평균단가 캐시
  - BOM 기반 원가 필드 추가:
    - `cost_type`: 원가유형 (MANUAL/BOM/PROCESS)

    - `calculated_cost`, `cost_calculated_at`: 계산된 원가 및 계산일시

- [x] **가격 이력 시스템 (PriceHistory)**
  - `price_history` 테이블 생성 (모든 가격 변동 기록)

  - 자동 원화 환산 기능

- [x] **원가관리 API 구현 (`/api/v1/prices`)**
  - `GET /prices/parts/{part_id}`: 부품 원가 정보 조회

  - `POST /prices/parts/{part_id}/refresh-cache`: 평균단가 캐시 갱신
  - `GET /prices/parts/{part_id}/avg-price`: 평균단가 계산 (기간별/건수별)
  - `GET /prices/parts/{part_id}/history`: 가격 이력 조회
  - `GET /prices/exchange-rates/{currency}`: 환율 조회
  - `POST /prices/exchange-rates`: 환율 등록
  - `GET /prices/convert`: 통화 환산

- [x] **BOM 기반 원가 계산 (v0.18.0 핵심)**
  - `GET /prices/parts/{part_id}/bom-cost`: BOM 기반 원가 계산
    - 단품: 기준단가/최근단가/재고단가 사용

    - 순환 참조 감지 및 방지
  - `GET /prices/parts/{part_id}/bom-cost/breakdown`: BOM 원가 분석 (트리 구조)
  - `POST /prices/parts/{part_id}/bom-cost/save`: 계산된 원가 저장
  - `POST /prices/parts/{part_id}/bom-cost/save-all`: BOM 전체 원가 재계산
  - `PATCH /prices/parts/{part_id}/labor-cost`: 가공비 업데이트
  - `PATCH /prices/parts/{part_id}/overhead-cost`: 경비 업데이트

- [x] **PriceService 구현**

### 원가 계산 로직 (BOM 기반)

```
원가 계산 우선순위:
┌─────────────────────────────────────────────────────────────┐
│  1. BOM 있는 경우 (조립품)                                   │
│     총원가 = 재료비 + 가공비 + 경비                          │
│     재료비 = Σ(하위부품 단가 × 수량)                         │
│                                                             │
│  2. BOM 없는 경우 (단품)                                     │
│     단가 우선순위: 기준단가 > 최근단가 > 재고단가             │
└─────────────────────────────────────────────────────────────┘

재고단가 계산 (이동평균법):
┌─────────────────────────────────────────────────────────────┐
│  신규 재고단가 = (기존재고금액 + 신규입고금액) / 총수량       │
│                                                             │
│  예시:                                                      │
│  - 기존: 100개 × 1,000원 = 100,000원                        │
│  - 신규: 50개 × 1,200원 = 60,000원                          │
│  - 신규 재고단가 = 160,000원 / 150개 = 1,066.67원           │
└─────────────────────────────────────────────────────────────┘

평균단가 계산:
┌─────────────────────────────────────────────────────────────┐
│  - avg_price_30d: 최근 30일 구매 이력의 평균                 │
│  - avg_price_90d: 최근 90일 구매 이력의 평균                 │
│  - avg_price_last5: 최근 5건 구매의 평균                     │
│  - avg_price_last10: 최근 10건 구매의 평균                   │
└─────────────────────────────────────────────────────────────┘
```

cd backend

uvicorn app.main:app --reload --host 0.0.0.0

```bash
cd frontend
npm run dev
```
- 로컬 URL: http://localhost:5173
- 네트워크 URL: http://{서버IP}:5173
- 코드 관리: /codes
- 부품 관리: /parts
- 거래처 관리: /partners

### 네트워크 접속 설정 (같은 네트워크의 다른 PC에서 접속)

PowerShell (관리자 권한)에서 실행:
```powershell
# 프론트엔드 포트 (5173) 허용
New-NetFirewallRule -DisplayName "X-Manager Frontend" -Direction Inbound -Port 5173 -Protocol TCP -Action Allow

# 백엔드 포트 (8000) 허용
New-NetFirewallRule -DisplayName "X-Manager Backend" -Direction Inbound -Port 8000 -Protocol TCP -Action Allow
```

#### 서버 IP 확인
```bash
ipconfig
```
IPv4 주소 확인 (예: 192.168.0.100)

#### 다른 PC에서 접속
브라우저에서 `http://192.168.0.100:5173` 접속

## 📌 주요 이슈 및 해결

### 1. Alembic 인코딩 문제
- **문제**: alembic.ini 파일의 한글 주석으로 인한 UnicodeDecodeError
- **해결**: 한글 주석을 영문으로 변경

### 2. Tailwind CSS 버전 문제
- **문제**: Tailwind v4가 자동 설치되어 @tailwind 디렉티브 에러
- **해결**: Tailwind CSS 3.4로 다운그레이드

### 3. SQLAlchemy JSON 필드 변경 감지
- **문제**: JSON 필드 업데이트 시 변경사항이 저장되지 않음
- **해결**: `flag_modified()` 함수로 명시적 변경 표시

### 4. URL 이중 프리픽스 문제
- **문제**: `/api/v1/api/v1/...` 형태로 URL 중복
- **해결**: 라우터 등록 및 프론트엔드 API 클라이언트 수정

### 5. Windows 콘솔 인코딩
- **문제**: PowerShell에서 한글 출력 시 UnicodeEncodeError
- **해결**: `io.TextIOWrapper`로 UTF-8 출력 설정
