# X-Manager 서버 설치 가이드

## 사전 조건
- Python 3.12+ 설치됨
- Node.js 20+ 설치됨
- PostgreSQL 16+ 설치됨
- Git 설치됨
- Caddy 설치됨 (C:\Caddy\caddy.exe)
- 도메인: xmanager.xbeamtech.co.kr → 서버 공인IP A레코드 설정 완료
- 포트포워딩: 80, 443 완료
- 방화벽: 80, 443 인바운드 허용 완료

## STEP 1: 코드 가져오기

```bash
cd C:\

cd X-MANAGER_R0.1
git checkout feature/yhs0121
```

---

## STEP 2: 백엔드 환경 구성

```bash
cd C:\X-MANAGER_R0.1\backend

# 가상환경 생성
python -m venv venv

# 패키지 설치
venv\Scripts\pip install -r requirements.txt

# bcrypt 호환 버전 설치
venv\Scripts\pip install bcrypt==4.0.1
```

---

## STEP 3: PostgreSQL DB 생성

PostgreSQL 설치 시 설정한 postgres 비밀번호로 접속:

```bash
psql -U postgres
```

아래 SQL 실행:
```sql
CREATE DATABASE xmanager;
\q
```

### DB 접속 설정 확인

backend/.env 파일이 있으면 DATABASE_URL 확인.
없으면 backend/app/core/database.py에서 직접 확인.

기본값: postgresql://postgres:[비밀번호]@localhost:5432/xmanager

> 비밀번호가 다르면 database.py 또는 .env 파일을 수정해야 함

---

## STEP 4: DB 테이블 생성 (마이그레이션)

```bash
cd C:\X-MANAGER_R0.1\backend
venv\Scripts\python.exe -m alembic upgrade head
```

성공하면 여러 줄의 `Running upgrade ...` 메시지가 출력됨.

### 에러 발생 시
- "connection refused" → PostgreSQL 서비스 실행 중인지 확인
- "password authentication failed" → DB 비밀번호 확인
- "database xmanager does not exist" → STEP 3 재확인

---

## STEP 5: 백엔드 실행 테스트

```bash
cd C:\X-MANAGER_R0.1\backend
```

## STEP 7: Caddyfile 설정

C:\Caddy\Caddyfile 파일을 아래 내용으로 생성 (메모장으로 편집):

```
xmanager.xbeamtech.co.kr {
    root * C:\X-MANAGER_R0.1\frontend\dist
    file_server

    handle /api/* {
        reverse_proxy localhost:8000
    }

    handle /health {
        reverse_proxy localhost:8000
    }

    try_files {path} /index.html
}
```

## 서비스 자동 시작 설정 (선택)

서버 재부팅 시 자동 실행하려면:

### 방법 1: 배치 파일

C:\X-MANAGER_R0.1\start-server.bat 생성:

```bat
@echo off
echo Starting X-Manager...

start "XM-Backend" cmd /k "cd /d C:\X-MANAGER_R0.1\backend && venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000"

start "XM-Caddy" cmd /k "cd /d C:\Caddy && caddy run --config Caddyfile"

echo X-Manager started!
```

### 방법 2: NSSM (Windows 서비스 등록)

NSSM 다운로드: https://nssm.cc/download

```bash
# 백엔드 서비스 등록
nssm install XManager-Backend "C:\X-MANAGER_R0.1\backend\venv\Scripts\python.exe"
nssm set XManager-Backend AppParameters "-m uvicorn app.main:app --host 0.0.0.0 --port 8000"
nssm set XManager-Backend AppDirectory "C:\X-MANAGER_R0.1\backend"
nssm start XManager-Backend

# Caddy 서비스 등록
nssm install XManager-Caddy "C:\Caddy\caddy.exe"
nssm set XManager-Caddy AppParameters "run --config C:\Caddy\Caddyfile"
nssm set XManager-Caddy AppDirectory "C:\Caddy"
nssm start XManager-Caddy
```

## 트러블슈팅

| 증상 | 원인 | 해결 |
|------|------|------|
| 사이트 접속 안 됨 | Caddy 또는 백엔드 미실행 | 두 터미널 모두 실행 중인지 확인 |
| 502 Bad Gateway | 백엔드 미실행 | 백엔드 터미널 확인 |
| DB 연결 실패 | PostgreSQL 미실행 | 서비스에서 postgresql 시작 |
| 인증서 에러 | DNS 미전파 | 1~2시간 대기 후 재시도 |
| 로그인 실패 | DB 마이그레이션 안 됨 | alembic upgrade head 재실행 |
| 포트 이미 사용 중 | 기존 프로세스 남아있음 | taskkill /F /IM python.exe |
